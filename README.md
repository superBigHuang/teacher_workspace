# 中学班主任工作平台

> 减负·不增负 —— 把花名册、座次、值日班委、课表、成绩、家校沟通、待办、考勤纪律作业收拢到一处的 Web 工作台。

## 技术栈

- 后端：Spring Boot 3 + Spring JDBC(JdbcTemplate) + MySQL + JWT + Apache POI（JDK 17）
- 前端：Vue 3 + Vite + Pinia + Element Plus（粉彩主题）+ ECharts + vuedraggable

## 目录结构

```
teacher_workspace/
├── backend/          # Spring Boot 后端（端口 8088）
├── frontend/         # Vue3 前端（端口 5173）
├── scripts/
│   └── seed.mjs      # 演示数据种子（50 名学生 + 课表 + 排座 + 轮值 + 两次成绩）
├── img/              # 原型图（9 张）
└── doc/需求/班主任工作平台/   # 需求说明、功能清单与数据模型
```

## 启动方式

### 0. 准备
- 需 JDK 17+、Node 18+、MySQL 5.7/8.x。
- 数据库连接在 `backend/src/main/resources/application.yml`，默认 `root/root`，
  数据库 `teacher_workspace` 会在首次启动时**自动创建建表并写入初始数据**（默认账号、科目、节次、规则、节假日等）。

### 1. 启动后端（端口 8088）
```bash
cd backend
# Windows 如默认 JDK 是 8，需指定 JDK17：
set JAVA_HOME=C:\Program Files\Eclipse Adoptium\jdk-17.0.18.8-hotspot
mvn spring-boot:run
```
> 注：本机 8080 被其他 Java 服务占用，后端使用 **8088**。

### 2. 启动前端（端口 5173）
```bash
cd frontend
npm install
npm run dev
```
浏览器打开 http://localhost:5173

### 3.（可选）灌入演示数据
```bash
cd scripts
npm install xlsx@0.18.5
node seed.mjs
```

## 功能模块

| 模块 | 说明 |
|---|---|
| 工作台 | 问候卡/校训箴言编辑、⚡一句话速记（离线关键词规则自动拆分到考勤/家校/作业/纪律/待办，弹窗勾选一键保存）、4 统计卡、6 张可拖拽排序的工作卡、节假日倒计时 |
| 花名册 | 总人数/男女/比例统计、性别筛选、搜索、增删改、Excel 导入导出、学生档案抽屉（家长+沟通+考勤+纪律+作业汇聚） |
| 座次表 | 行/列/3 过道配置、男女交错随机排座、拖拽交换座位、讲台视图 |
| 值日表·班委 | 值日事项标签、每日人数、按花名册自动轮值（顺延）、手动增删、班委名单 |
| 成绩分析 | xlsx 导入（学号自动匹配）、各科均分/最高最低/及格率/优秀率、分数段柱状图、单科折线（平均线）、明细排名表、双考试进退步对比 |
| 家长联系方式 | 通讯录（父母姓名电话/住址）、搜索、沟通记录、沟通弹窗（家长联动） |
| 课程表 | 班主任班/任课班 tab、周课表、自定义节次、科目管理（颜色/教师）、底部科目图例拖拽排课、周末可排课 |
| 待办事项 | 分类（教学/班级/家校/其他）、截止日、完成勾选、逾期高亮、速记自动生成 |
| 班级日常 | 早读考勤（出勤/迟到/请假/缺勤）、课堂纪律、作业收缴（勾未交），入口在工作台卡片或侧边 `/daily` |

## 说明
- 单教师账号，表结构与接口已预留 `user_id`/多用户扩展。
- 任课班仅用于课程表，不建学生档案。
- 速记为离线关键词规则（存表 `quick_note_rule`，可在库中增配关键词），无需联网或 API Key。
