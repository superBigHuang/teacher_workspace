## 二、速记规则（quick_note_rule 初始数据）

| module_key | 关键词 | 归档 |
|---|---|---|
| ATTENDANCE | 迟到,早退,请假,缺勤,旷课,考勤 | 早读考勤 |
| COMM | 电话,家长,沟通,联系,微信,家访 | 家校沟通 |
| HOMEWORK | 作业,未交,催,收齐,补交 | 作业收缴 |
| DISCIPLINE | 违纪,说话,零食,打架,捣乱,课堂 | 课堂纪律 |
| TODO | 准备,班会,PPT,活动,记得,需要,别忘了,提醒 | 待办事项 |

- 人名：按花名册姓名/学号子串匹配，命中即关联学生。
- 一条速记可命中多模块；按 "/"、"；"、换行 切分句段，逐段归类。
- 无任何命中 → 默认进待办。
- 解析结果弹窗预览，用户勾选确认后批量落库。

## 四、关键算法

- **随机排座**：取在籍学生，按性别分组后洗牌，采用"男女交替入位 + 同位冲突重试"，在 rows×cols 网格（剔除过道列）依次放置，保证男女尽量交错。
- **自动轮值**：取花名册顺序，维护轮值指针；按周一~周五 person_count 顺序切片分配，写入 duty_roster（round 自增）；再次轮值从指针继续顺延。
- **成绩统计**：均分=avg、最高/最低、及格率=≥pass_line 占比、优秀率=≥excellent_line 占比；分数段五档；排名按总分降序；对比表按学号 join 两次考试算各科分差与排名差。
- **节假日倒计时**：取今天之后最近的节日显示大数字，其余横排显示天数。
