# 中学班主任工作平台 — 需求说明

> 本文件为需求基线。完整功能清单见同目录《功能清单与数据模型.md》。

## 一、背景与问题描述

班主任日常工作分散在纸质表格、Excel、微信记录中：花名册、座次、值日、课表、成绩、家长沟通、待办等数据互不连通，重复录入多。本平台参考原型图（`img/` 下 9 张，v3.5 桌面端样式）构建 Web 版班主任工作台，把班级管理日常收拢到一处，口号"减负·不增负"。

## 二、目标与非目标

**目标**
- 一个页面统管：花名册、座次、值日班委、成绩分析、家长联系、课程表、待办、工作台日常（考勤/纪律/作业）。
- 数据一次录入多处复用（学生信息贯穿花名册/家长/座次/成绩/档案）。
- "一句话速记"用离线关键词规则把口语记录自动拆分归档到各模块。
- 粉彩卡片风 UI，贴近原型，老师零学习成本。

**非目标（本期不做）**
- 多教师注册/权限体系（仅单账号，但表结构与接口预留 user_id）。
- 任课班学生管理（任课班仅用于课程表排课，不建学生档案）。
- 大模型在线归类（仅规则引擎，规则可配；预留 AI 适配层位置）。
- 移动端适配（以桌面浏览器为主）。
- 侧边栏"🔒"图标语义不明，本期不实现。

## 三、需求范围（8 模块）

| 模块 | 要点 |
|---|---|
| 登录 | 单密码进入，JWT 鉴权，预留 user 表 |
| 工作台 | 问候卡（教师/学期/校训/箴言可编辑）、⚡一句话速记（规则归类+预览弹窗+一键保存）、4 统计卡、6 张可拖拽排序的工作卡片（早读考勤/我的课表/节假日倒计时/今日课程/课堂纪律/作业收缴） |
| 花名册 | 总人数/男/女/比例统计卡、性别筛选、姓名学号搜索、增删改、Excel 导入导出、清空、学生档案抽屉（基本信息+家长+沟通+考勤/纪律/作业汇聚） |
| 座次表 | 行数/列数/3 过道配置、随机排座（男女尽量交错）、手动拖拽交换、讲台视图、清空、持久化 |
| 值日表·班委 | 值日事项标签增删、周一~周五每日人数、自动轮值（按花名册顺延）、手动增删人、班委名单（学生+职务） |
| 成绩分析 | xlsx 导入（学号匹配）、考试管理、各科统计卡（均分/最高/最低/及格率/优秀率）、分数段柱状图、科目折线图（平均线+高低均统计）、明细表（排名/总分/均分）、双考试对比（各科分差/总分/排名变化） |
| 家长联系方式 | 通讯录（父母姓名电话/住址）、搜索、沟通记录列表、沟通弹窗（家长联动+记录增删） |
| 课程表 | 班级 tab（班主任班+任课班）、周课表网格（早自习~晚自习2、周一~周日）、自定义节次、科目管理（颜色/教师）、科目图例拖拽排课、多班独立保存 |
| 待办事项 | 标题/分类（教学·班级·家校·其他）/截止日/完成状态；增删改、筛选、逾期高亮、速记自动生成 |

**班级日常登记**（工作台卡片入口 + 独立登记界面）
- 早读考勤：按日全班勾选（出勤/迟到/请假/缺勤），默认全勤，可按日/学生查询。
- 课堂纪律：登记违纪事件（日期/学生可多选/内容），按日倒序。
- 作业收缴：按日+科目登记，默认已交，勾选未交；可查学生历史。

## 四、影响范围

- 新建工程：`backend/`（Spring Boot 3 + MyBatis-Plus + MySQL 8 + JWT + POI）、`frontend/`（Vue3 + Vite + Pinia + Element Plus + ECharts + vuedraggable）。
- 依赖环境：JDK 17+（本机 Adoptium 17.0.18 可用）、Node 20、MySQL 8、Maven 3.8。
- 数据库：新建库 `teacher_workspace`，约 20 张表（见功能清单文档）。

## 五、验收标准

1. 密码登录可进入，刷新保持登录态。
2. 花名册增删改查、筛选、搜索、Excel 导入导出、清空可用，统计卡数字正确。
3. 课程表拖拽排课、自定义节次/科目、班主任班/任课班独立保存。
4. 座次表随机排座男女分布合理、过道正确、手动调整刷新后保留。
5. 值日自动轮值按人数生成、可手动增删；班委可增删。
6. 成绩导入后各科统计、分数段、折线、明细、双考对比（分差/排名）正确。
7. 家长沟通记录增删、弹窗家长联动、搜索有效。
8. 待办增删改、完成勾选、筛选、逾期高亮、速记自动生成。
9. 考勤/纪律/作业登记→查询→学生档案汇聚链路通。
10. 工作台 4 统计卡与各模块一致；速记示例句能正确拆分多模块；卡片顺序刷新保留；节假日倒计时正确。
11. 数据持久化 MySQL，重启不丢失。

## 六、待确认问题（默认方案，可后调）

- 及格线 60 / 优秀线 85（百分制），设置页可改。
- 节假日内置当年常见节日（中秋/国庆/圣诞/元旦等），可手动增删。
- 任课班不建学生档案，课表仅排课。

## 七、方案结论摘要

- 架构：Spring Boot 3（JDK17）+ Vue3 + MySQL 8，前后端分离，JWT 单账号登录、预留多用户。
- 速记：离线关键词规则引擎，规则存表可配；无法识别默认进待办；识别后弹窗预览勾选再保存。
- 实施顺序（数据依赖驱动）：骨架与登录 → 花名册 → 家长 → 课程表 → 座次 → 值日班委 → 待办 → 日常三件套 → 成绩 → 工作台聚合 → 联调验收。
- 验证：JUnit 覆盖规则引擎/排座/轮值/成绩统计；导入原型同款示例数据对照 9 张原型走查。
