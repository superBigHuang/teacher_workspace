# 座次表·宠物园：批量评价支持按列（列头勾选）全选

> 2026-09-03。老师需求："座次表·🐾宠物园 的批量评价列头也加一个选择框，可以按列选择"。

## 背景与问题

`Seat.vue` 批量评价模式（batchMode）下，每个座位/宠物卡右上角有 `el-checkbox` 逐个勾选（`selected` 为学生 id 集合，逻辑在 `composables/usePets.js`）。老师想**按整列快速勾选**（如给某一列学生统一评价），目前只能一个个点。

## 目标

批量评价模式下，座位棋盘**每一列的列头**（"第 N 列"处）显示一个选择框：
- 勾选 → 该列所有已排座学生全部选中；
- 取消 → 该列全部取消；
- 该列部分选中时，选择框显示**半选**（indeterminate）状态。

## 方案结论（纯前端，无后端/表变更）

- 列头 `.col-label`（`Seat.vue` 顶部列名，gridRow=1）在 `batchMode` 时把"第 N 列"文本换成 `el-checkbox`：
  - `:model-value="colAllChecked(c)"`（该列有学生且全部在 selected 中）
  - `:indeterminate="colIndeterminate(c)"`（部分选中）
  - `@change="toggleCol(c)"`
- 新增三个辅助函数（基于现有 `seats`（含 row/col/studentId）与 `selected`）：
  - `colStudentIds(c)`：`seats.filter(s => s.col === c && s.studentId).map(s => s.studentId)`
  - `colAllChecked(c)`：ids 非空且 `ids.every(id => selected.has(id))`
  - `colIndeterminate(c)`：选中数 >0 且 < ids 总数
  - `toggleCol(c)`：未全选则把该列 id 全部加入，已全选则全部移除（沿用 usePets 的"复制新 Set 再赋值"响应式写法：`selected.value = new Set(...)`）。
- 非批量模式列头仍显示"第 N 列"文本，不变。
- 列头选择框仅作用于**座位棋盘**的列（未排座学生区不在列内，不涉及）。

## 影响范围

- 前端：`frontend/src/views/Seat.vue`（col-label 模板 + 4 个辅助函数 + 少量样式）。
- 复用：`usePets()` 的 `selected`（ref Set）、`batchMode`；座位列号 `cols`、逻辑列→显示列 `displayCol`（过道偏移已由 gridColumn 处理，列头与座位同列对齐）。
- 后端/数据：无改动。
- E2E：批量模式下列头勾选 → 该列学生选中数 = 该列人数；再点取消清空；半选状态（可选断言）。

## 验收标准

1. 进入批量评价，每列列头出现选择框。
2. 点某列列头：该列所有有学生的座位全部勾选，顶部"已选 N 名"增加该列人数；再点取消该列。
3. 该列只勾了部分学生时，列头框显示半选。
4. 空座位/过道不影响；非批量模式下列头恢复为"第 N 列"文本。

## 落地结果（2026-09-03 完成）

- 前端 `Seat.vue`：
  - 列头 `.col-label` 在 `batchMode` 时把"第 N 列"文本换成 `el-checkbox`（`:model-value="colAllChecked(c)"`、`:indeterminate="colIndeterminate(c)"`、`@change="toggleCol(c)"`，`@click.stop` 防冒泡到座位）。
  - 新增 4 个辅助函数：`colStudentIds(c)`（该列已排座学生 id，空位不计）、`colAllChecked`（非空且全选）、`colIndeterminate`（选中数 >0 且未满）、`toggleCol`（未全选整列加入 / 已全选整列移除，复制新 Set 再赋值触发响应式）。
  - 非批量模式列头仍显示"第 N 列"；未排座空位/过道不影响。
- 后端/数据：无改动（复用 usePets 的 `selected`/`batchMode`）。
- E2E：新增 7c 步骤——批量模式列头出勾选框；点列头整列选中（is-checked）、再点取消归 0；找 ≥2 人的列全选后取消其中 1 个座位，列头变半选（Element Plus 半选 class `is-indeterminate` 在内部 `.el-checkbox__input` 上，外层 label 为 `aria-checked="mixed"`）。纯前端选择不提交评价、不写库。全量 E2E 通过。
