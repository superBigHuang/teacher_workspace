# 科目「我教的」勾选标记（替代 teacher 文本猜测）

> 2026-09-03。老师提出："自己的任课是不是匹配的是字符串『我』，有些老师不填『我』会匹配不到。"经确认采用**显式勾选**方案。

## 背景与问题

工作台「我的课表/今日课程/本周剩余」和班级日常「作业收缴科目下拉」要判断"哪些课是我上的"。旧逻辑靠 `subject.teacher` 自由文本猜：

- 后端 `DashboardController.stats`：`teacher='我' OR teacher=教师姓名`（teacher_name 兜底 display_name）；
- 前端今日课程轴：`cell.teacher==='我' || ===teacher_name`；
- 前端作业科目下拉：`!teacher || ==='我' || ===teacherName`。

三个问题：
1. **强依赖填"我"**：老师给自己教的科目若填真实姓名（如"孙老师"）、而设置里教师姓名/显示名称没对上，就匹配不到。
2. **三处不一致**：任课教师**留空**时，作业下拉算"我的"，但后端统计不算。
3. 教师姓名写法无法穷尽（孙老师/孙某/全名）。

## 目标

给科目一个显式的「我教的」布尔标记，所有"我的课/我的科目"判定统一读它，不再靠 teacher 文本猜。teacher 字段仍保留（课表上显示任课教师名）。

## 方案结论

### 数据
- `subject` 表新增 `is_mine TINYINT NOT NULL DEFAULT 0`（1=我任教）。
- `DataInitializer` 启动迁移：**仅首次加列当次** `UPDATE subject SET is_mine=1 WHERE teacher='我'`（旧数据里明确填"我"的科学/班会/自习自动勾选）；填真实姓名的科目无法自动判定，升级后老师在"管理科目"手动勾一次即可。之后老师勾选/取消不再被覆盖。

### 后端
- `TimetableController`：`subjects` 查询返回 `is_mine isMine`；新增/更新科目读写 `is_mine`（`boolBody` 兼容 true/false、1/0、"true"/"1"）；`grid` 返回 `sub.is_mine isMine`。
- `DashboardController.stats`：今日课程/今日剩余/本周剩余 SQL 由 `(s.teacher='我' OR s.teacher=?)` 改为 `s.is_mine=1`；删除仅用于此的 teacher_name 三段查询。

### 前端
- `Timetable.vue` 管理科目弹窗：表格加「我教的」列（el-checkbox，change 即保存）；新增科目默认不勾。
- `Settings.vue` 我的学科：每个学科 tag 加「我教的」小勾选（切换即 PUT）；新增行加勾选。
- `Dashboard.vue loadTodayCourses`：`if (!cell.isMine) continue`。
- `Daily.vue mySubjects`：`subjects.filter(s => s.isMine)`；删除 teacher_name 拉取。

## 影响范围
- 后端：`schema.sql`、`DataInitializer.java`、`TimetableController.java`、`DashboardController.java`。
- 前端：`Timetable.vue`、`Settings.vue`、`Dashboard.vue`、`Daily.vue`。
- 数据：subject 加一列，存量 teacher='我' 自动勾选；其余老师手动勾。
- E2E：作业科目断言改 isMine，并用临时科目验证"勾选→下拉出现 / 取消→消失"。

## 验收标准
1. 管理科目/我的学科里勾选某科「我教的」，工作台今日课程/本周剩余、作业科目下拉立即计入；取消则不计入。
2. 不再依赖任课教师填"我"或姓名；teacher 留空/填名字都不影响，只看勾选。
3. 升级后原来填"我"的科目保持勾选状态；课表上任课教师名照常显示。

## 落地结果（2026-09-03 完成）

- 后端：`subject` 加 `is_mine` 列（schema.sql + DataInitializer 首次加列当次回填 `teacher='我'`，实测科学/班会/自习自动 isMine=1）；`TimetableController` 科目 CRUD/grid 返回并读写 isMine（`boolBody` 兼容布尔/数字/字符串）；`DashboardController.stats` 今日课程/剩余 SQL 改 `s.is_mine=1`，删除 teacher_name 三段查询。
- 前端：`Timetable.vue` 管理科目弹窗加「我教的」勾选列（弹窗加宽到 620px）；`Settings.vue` 我的学科 tag + 新增行加勾选（`toggleMine` 即切即存）；`Dashboard.vue` 今日课程轴改判 `cell.isMine`；`Daily.vue` 作业科目改 `filter(s=>s.isMine)`，移除 teacher_name 拉取。
- E2E：个人设置步骤随推送抽屉调整；作业科目步骤改用临时科目 `E2E我教科目`（isMine=true 出现在下拉、取消勾选后消失，finally 删除），断言"我教的都在、别人教的都不在"。全量 E2E 通过（1 passed，1.7m），跑完无临时科目残留。
- 备注：任课教师填真实姓名（孙老师等）的科目无法自动判定归属，老师在"管理科目/我的学科"勾一次「我教的」即可，之后与 teacher 文本无关。
