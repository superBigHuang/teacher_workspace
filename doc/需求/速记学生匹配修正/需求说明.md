# 一句话速记：学生匹配修正（子串误命中 + 多人静默取第一个）

> 2026-09-03。工作台联动收尾时发现、经老师确认后修复。

## 背景与问题

一句话速记 `POST /dashboard/quicknote/parse` 分句后，用 `text.contains(姓名)` / `text.contains(学号)` 匹配学生，前端 `doParse` 对每条归类取 `seg.students[0]` 作为关联学生。排查发现**真正根因在学号**：

- 本班学生学号是 `1、2、3…40` 这样的**短序号**。裸 `contains(学号)` 下，任何含数字的速记都会误命中——历史上"陈俊琪"（学号=**2**）被反复误记，就是因为速记句里的 **"E2E" 含数字 "2"**；日期"2026"、数量"1分钟"、多位数"12"同理都会撞上短学号。
- 另有姓名子串问题：若"陈俊"是"陈俊琪"名字子串，写"陈俊琪迟到"会连带匹配"陈俊"。
- 多人命中时前端只静默预选 id 最小的 `students[0]`，老师不细看就"一键保存"，误记到错误学生头上。

## 目标

- 短名仅作为长名子串出现时不误命中；短名独立出现时仍能命中。
- 一句话命中多名学生时，不再静默只取第一个；为每名学生各生成一条归类记录，由老师在预览中核对/取消。

## 方案结论

### 后端（`DashboardController.parse`）

两条规则同时收紧：

**A. 学号只认"带号语境"（核心修复）**

- 不再用裸 `text.contains(学号)`（短学号 1/2/3 会被 E2E、日期 2026、数量"1分钟"误命中）。
- 学号必须与"号"字相邻才命中：正则 `(?<![A-Za-z0-9])N号`（如"2号迟到"）或 `号N(?![A-Za-z0-9])`（如"学号2迟到"）。
- 前后用 ASCII 字母数字 lookaround 边界（不用 Java `\b`——实测 `\b` 在中文与数字间不构成词边界），防止"12号"误命中学号 2。
- 效果："E2E…迟到"/"2026开学"/"迟到1分钟"/"扣2分"/"2 迟到" → 学号都不命中；"2号迟到"/"学号2迟到" → 命中学号 2（陈俊琪）；"12号迟到" → 命中学号 12，不误中 2。

**B. 姓名最长匹配 + 剩余文本**

- 学生按姓名长度降序；维护 `remain = 分句文本`。
- `remain.contains(姓名)` 命中则加入结果，并把该姓名从 `remain` 移除（`replace`），再判更短的名字。
- 效果："陈俊琪迟到" → 长名命中移除后"陈俊"找不到 → 不误命中；"陈俊和陈俊琪迟到" → 长名移除后剩余仍含独立"陈俊" → 短名保留。

### 前端（`Dashboard.vue doParse`）

- 需要学生的模块（ATTENDANCE/COMM/HOMEWORK/DISCIPLINE）：
  - 命中多名学生 → 为每名学生各生成一条 entry（各自预选正确学生）；
  - 命中 0 名 → 一条留空，由老师手选（`confirmSave` 原有"未关联学生"拦截保留）。
- 无需学生的模块（TODO 待办）：仍一条、不带学生。
- 预览弹窗每条 entry 的学生下拉保持可改、可取消勾选。

## 影响范围

- 后端：`DashboardController.java`（仅 parse 方法内学生匹配段）。
- 前端：`Dashboard.vue`（仅 doParse 的 entry 生成循环）。
- 数据/表：无变更。
- E2E：新增子串去重（API 断言）+ 多人拆分（UI 断言 2 条 entry）步骤；用临时学生、finally 删除，不污染真实数据。

## 验收标准

1. 含数字的速记（E2E、日期、数量）不再误关联到短学号学生；"N号/学号N"语境仍能按学号命中。
2. 速记含长名学生时，不因子串误关联到短名学生。
3. 速记同时提到两名学生（或短名独立出现 + 长名）时，预览里对应模块为每名学生各生成一条，且学生下拉预选正确。
4. 单学生速记行为不变（自动预选该生）；无学生时仍提示手选。

## 落地结果（2026-09-03 完成）

- **后端 `DashboardController.parse`**：
  - 学号匹配收紧为正则 `(?<![A-Za-z0-9])N号` 或 `号N(?![A-Za-z0-9])`（ASCII 字母数字边界，不用 Java `\b`——实测中文/数字间 `\b` 不生效）；裸 `contains(学号)` 废弃。
  - 姓名按长度降序 + `remain` 剩余文本移除：长名命中后从 remain 删除，短名仅在独立出现时命中。
- **前端 `Dashboard.vue doParse`**：需学生模块（ATTENDANCE/COMM/HOMEWORK/DISCIPLINE）按命中学生各生成一条 entry；0 命中仍留一条空手选（`confirmSave` 未关联拦截保留）。
- **PowerShell 实测 10 个场景全对**："E2E测试生今天迟到"→仅 E2E测试生；"E2E测和E2E测试生今天都迟到"→两人；"2号迟到"/"学号2迟到"→陈俊琪(学号2)；"12号迟到"→孔婉柠(学号12，不误中2)；"迟到1分钟"/"扣2分"/"2026开学"/"2 迟到"→学号均不命中。
- **E2E**：新增 10b 步骤（临时短名学生 E2E测/997，finally 删除）——API 断言子串去重 + 多人命中；UI 断言预览 2 条 entry、分别预选 `E2E测（997）`/`E2E测试生（999）`。全量 E2E 通过（1 passed，2.2m），跑完无 E2E 临时学生残留。
