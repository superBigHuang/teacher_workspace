# 家长成绩通知单 需求说明

## 背景与问题
- 考试后家长最关心成绩，但微信群直接发分数表既不合规也不方便；老师目前只能逐个私信或截图。
- 成绩分析模块已有完整的分数、排名、进退步数据，缺一个"面向家长的出口"：一份正式、好看、可打印/可发图片的个人报告单。
- 通知单同时承载教育沟通功能：除分数外，让家长看到孩子的考勤、作业、纪律表现和老师寄语。

## 目标
1. 选定一次考试（可选对比考试），一键生成全班每个学生的**家长版成绩通知单**。
2. 报告单内容：抬头（学校/班级/学期/考试名）、学生信息、各科成绩与班级对照、总分与班级排名、进退步、本学期日常表现摘要、教师寄语、家长签字栏。
3. 输出方式：浏览器打印（A4，每生一页，可直接另存 PDF）；图片导出（发微信）作为 v2 可选。

## 非目标
- 不做家长登录端/家长自助查询（通知单由老师导出后私发）。
- 不做短信/微信自动推送。
- 不做等级制换算规则自定义（固定：分数+排名呈现；等级按分数段 A/B/C/D 可配）。

## 需求范围

### A. 报告单内容（每生一页 A4）
1. **抬头**：学校名（设置.school）、班级（班主任班名）、学期（设置.term）、考试名称与日期。
2. **学生信息**：姓名、学号、班主任（设置.teacher_name）。
3. **成绩表**：各科 | 得分 | 班级平均分 | 班级最高分 | 等级（A≥优秀线 / B≥及格线 / C<及格线）；缺考科目显示"—"。
4. **总评**：总分、班级排名（X / 总人数）、对比上次考试的排名变化（↑N / ↓N / 新 / —）。
5. **日常表现摘要**（本学期，按学期起止日期）：全勤情况（迟到 X 次 / 请假 X 天）、作业未交 X 次、纪律记录 X 条——数字中性呈现，不做道德评价。
6. **教师寄语**：**AI 逐人生成（30~80 字，结合成绩与表现，详见《AI助手接入》需求）**；AI 不可用时降级为"已写评语取摘要，否则用统一寄语"（个人设置新增"通知单统一寄语"文本）；报告单页可逐生临时编辑。
7. **落款**：班主任签名行 + 日期 + 家长签字栏。

### B. 操作流程
- 入口：成绩分析页考试操作栏新增「📄 家长通知单」按钮。
- 弹窗配置：选择考试（默认当前考试）、对比考试（可选，不选则不显示进退步）、勾选附带内容（日常表现摘要/教师寄语，默认全选）、统一寄语文本。
- 点「生成」→ 新窗口打开打印版报告（每生一页，连续排版）→ 浏览器 `window.print()` 打印/另存 PDF。
- 打印版为独立路由（无侧边栏的空白布局），样式 A4 定向（@media print + @page）。

### C. 数据接口
- `GET /score/report?examId=&compareExamId=` 返回报告数据包：
  - 考试信息、班级名、学期、学生列表；
  - 每生：各科 {subject, score, classAvg, classMax, grade}、total、rank、totalStudents、rankChange、
    attendanceSummary {late, leaveDays}、homeworkMissing、disciplineCount、comment（寄语摘要）。
- 排名/均分逻辑复用成绩分析现有计算；日常表现按学期区间从 attendance/leave_record/homework_check/discipline_log 聚合（与评语素材共用聚合逻辑）。

## 影响范围
- 后端：ScoreController 增 `/score/report`；成绩/表现聚合服务（与评语素材接口共用底层）。
- 前端：新增打印页 `views/ScoreReport.vue` + 独立路由（/print/report，不走 MainLayout，带 token 同源可访问）；成绩页加按钮与配置弹窗；设置页加"统一寄语"。
- 依赖：纯打印无新依赖；图片导出（v2）需 html2canvas + JSZip。

## 验收标准
- 选一次考试生成全班通知单：每生一页，科目齐全、均分/最高/等级正确，排名与成绩明细页一致。
- 选对比考试后显示排名变化（↑/↓/新），与对比表一致；不选则无进退步列且不报错。
- 日常表现摘要数字与班级日常/请假模块一致；请假天数取自请假记录。
- 寄语：已写评语的学生取评语摘要，未写的取统一寄语。
- 浏览器打印预览为 A4 分页，每生一页，无侧边栏/按钮等界面元素。
- E2E：API 层校验报告数据包（人数=40、字段齐全、rank 连续）；打印页路由可打开。

## 待确认
1. 图片导出（每生一张 PNG 打包 zip，直接发微信）是否本期做？建议 v2：打印另存 PDF 已能满足大部分场景。
2. 等级线是否复用设置里的及格线/优秀线（60/85）？建议直接复用。
3. 报告单是否显示"家长签字栏"（纸质打印场景需要，纯图片发送不需要但保留无妨）。建议保留。

## 方案结论摘要
成绩模块数据的"家长向出口"，后端只加一个聚合接口，核心工作在 A4 打印排版；与评语助手共用表现数据聚合，建议两个需求同期开发，底层聚合服务只写一遍。

## 落地结果

### ④ 家长成绩通知单（2026-09-01 完成）

**后端**（ScoreController，复用 TermStatsService 聚合）：
- `GET /score/report?examId=&compareExamId=`：抬头（学校/班级/学期/考试名+日期/班主任/及格线优秀线/统一寄语）+ 全班在籍学生列表（以花名册为主表，缺考学生也出页，成绩"—"、rank 为 null）；每生各科 {subject, score, classAvg, classMax, grade}、total、rank、totalStudents、rankChange（对比考试排名差，无前次排名则 null）、attendance{late, leaveDays}、homeworkMissing、disciplineCount、comment（统一寄语兜底）。
- 排名口径与成绩明细页一致（SUM(score) 降序）；等级三档：A≥优秀线 / B≥及格线 / C<及格线，缺考"—"。

**前端**：
- 成绩分析页工具栏加「📄 家长通知单」按钮 → 配置弹窗（考试/对比考试可选/附带内容勾选：在校表现、教师寄语/寄语方式：✨AI 逐人生成 or 统一寄语/统一寄语文本框）。
- AI 寄语：前端 3 worker 并发调 `POST /ai/generate?scene=message`，el-progress 进度条 + "约需 2 分钟"提示；单人失败保留统一寄语兜底。
- 新增独立路由 `/print/report`（不套 MainLayout）+ `views/ScoreReport.vue`：A4 每生一页（@page A4 + page-break-after），含成绩表、总分排名、进退步（↑绿/↓红/持平）、在校表现四格、虚线框寄语（AI 生成带 ✨ 标记）、班主任签名 + 家长签字栏压底；数据经 sessionStorage 传新窗口。
- 修复：v-for 对 `data.students` 空值保护（无 sessionStorage 数据时显示 el-empty 空态，不白屏）。

**验证**：`npm run build` 通过；E2E 步骤 5b 覆盖——报告包 40 人、字段齐全、grade 枚举合法、rank 连续、打印页路由可打开；全量回归 1 passed。

**与原设计的偏差（备忘）**：
- 等级为 A/B/C 三档（无 D）；排名变化无"新"标记，无前次数据显示"—"。
- "已写评语取摘要"未做（评语表在 ⑤ 评语助手才建）；本期寄语 = AI 逐人生成 / 统一寄语（弹窗文本，留空取个人设置 report_message）。
- 打印页只读，不支持逐生临时编辑（可在生成前改统一寄语，或打印 PDF 后批注）。
- 待确认 1/2/3 结论：图片 PNG 打包 v2 不做；等级线复用设置及格线/优秀线；家长签字栏保留。
