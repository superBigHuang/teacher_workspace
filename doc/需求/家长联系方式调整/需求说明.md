# 家长联系方式页调整（编辑入口 + 沟通记录收纳）

## 背景与问题

家长联系方式页（Parent.vue）现状三个问题（用户 2026-09-02 反馈）：

1. 通讯录操作列只有「💬 沟通」，**无法编辑**家长姓名/电话/住址，要改只能去花名册。
2. 「📝 家校沟通记录」全量平铺在页面下方，信息过载；记录应在点开具体学生后才看得到。
3. 左上角「沟通记录」按钮行为莫名其妙——点击直接打开通讯录第一个学生的沟通弹窗（像"直接添加记录"），无语义、无入口价值。

## 目标

1. 通讯录操作列增加「✏️ 编辑」：弹窗编辑住址 + 父亲/母亲姓名电话，复用花名册同款接口 `PUT /roster/student/{id}`（后端零改动）。
2. 删除页内平铺的全量沟通记录表；沟通记录只在「💬 沟通」弹窗内按学生查看/添加/删除（弹窗能力已具备，保留）。
3. 删除工具栏「沟通记录」按钮。
4. 连带删除「清空记录」按钮：平铺表移除后该按钮无作用对象（看不到数据却能一键清空全部，危险且突兀）；逐条删除在沟通弹窗内保留。后端 `/parent/logs/clear`、`/parent/contact` 接口保留不删。

## 非目标

- 花名册学生档案抽屉（已含家长信息+沟通记录+编辑）不改。
- 家长关系仍固定父亲/母亲两行（与花名册编辑表单一致；系统无"其他"家长的产生路径）。

## 影响范围

- 前端：`frontend/src/views/Parent.vue`（工具栏、通讯录操作列、删除平铺卡片、新增编辑弹窗）
- E2E：`e2e/tests/e2e.spec.js` 步骤 6 增加编辑弹窗"改值→保存→复原"断言（不污染真实学生数据）
- 后端：无改动

## 验收标准

- [ ] 通讯录每行有「编辑」按钮，弹窗可改住址/家长姓名电话，保存后表格刷新生效
- [ ] 页面下方不再平铺沟通记录；工具栏无「沟通记录」「清空记录」按钮
- [ ] 「💬 沟通」弹窗内记录列表、添加、删除功能不变
- [ ] E2E 全绿

## 方案结论摘要

编辑弹窗字段与花名册 `saveStudent` 完全一致（stuNo/name/gender 只读带入 + address + parents 两行），直接 PUT；删除全量 logs 状态与 loadLogs 调用，弹窗内 delLog/addLog 只刷新 curLogs。
