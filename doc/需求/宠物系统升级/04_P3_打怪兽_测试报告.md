## 二、自动化测试结果

**命令**：`cd e2e && npx playwright test --reporter=line`
**结果**：`2 passed (2.1m)` —— 全站走查（含 11k 打怪兽段 ①~⑪）+ 拔萝卜免登，全绿。

11k 段断言要点：
- 开局前 `today=null`、未开始出题被拒；开始后 HP 满、`today` 响应**无 answer 字段**。
- 出题响应手机端有答案；`needPass = ceil(hp_total/hit_per_pass) = 10`。
- 答错：HP 不变、`stats.fail=1`、题目清空、**BOSS 流水 0 条**、未出题判定被拒。
- 连续 10 轮答对：`status=KILLED`、`hp_left=0`、`kill_student_id` 正确、`stats.pass=10`、击杀后出题被拒。
- 三档奖励按流水 remark 分类断言：通关 ×10（每条 +5）、击杀 ×1（+10）、全班同庆 ×1（+2，测试生在班主任班内也吃同庆），总分动态吻合。
- reset 后：`today=null`、BOSS 流水清零、**真实学生宠物 exp 回滚到判定前**（全班 +2 零污染）。
- 大屏 `/boss` 等待封面 `.wait-title`「今日还没有怪兽」可见。

构建：后端 `mvn package` 通过、已重启 8088；前端 `vite build` 通过（Boss.vue chunk 正常）。

## 三、手动双屏自测清单（localhost，约 15 分钟）

前置：前端 dev server 已起（5173）；后端 8088 在跑；题库里有**已启用**的题（/pet 题库管理录过题，否则出题提示先录题）。

1. **窗口 A（大屏/投影）**开 `http://localhost:5173/boss` —— 深色舞台，显示「今日还没有怪兽」等待封面。
2. **窗口 B（手机遥控）**开 `http://localhost:5173/m` → 输密码登录 → 点「👾 今日打怪兽」卡。
3. **开局**：B 里选分类+难度 → 点开始 → 看 **A 几乎实时**（SSE）跳出怪兽 emoji+名字+满 HP 红条；B 同步显示 HP。再点一次开始，怪兽不重建。
4. **出题防泄漏**：B 点「🎲 出题」→ B 显示题目+**答案**（老师可见）；**A 只显示题目、没有答案**。
5. **抽人**：B 点「随机抽人」或下拉点名 → **A 脉冲高亮**「请 xxx 作答」。
6. **答对**：B 点「✅ 答对 +5」→ A 上怪兽**抖动 + 飘「-10」**、HP 条降一截、✅ 计数 +1。
7. **答错**：再出题→抽人→B 点「❌ 未答对」→ A 上 **HP 不动**、❌ 计数 +1。
8. **击杀**：重复「出题→抽人→答对」约 10 次 → 最后一击时 A 上怪兽**爆炸消失 + 三发金色彩带雨 + 全屏「xxx 击杀！」**播 3 秒；B 震动+成功提示。
9. **击杀后**：B 再点出题 → 提示「今天的怪兽已经倒下啦」。
10. **加分核对**：去座次表 / /pet 看被抽中学生宠物成长值涨了（+5/+10），跨级的会补播进化。

手动重点看 E2E 看不到的 3 件事：
- **SSE 实时性**：B 点一下 A 多久动（应近瞬时；断网时 15s 轮询兜底）。
- **动画体感**：怪兽摆动/受击抖动/爆炸金雨/答题人脉冲，是否热闹、有无卡顿。
- **投影可读性**：HP 条、题目、学生姓名在教室最后一排能否看清。

## 四、测试数据清理（自测后必读）

手动自测会给**真实学生宠物**加成长值（通关 +5 / 击杀 +10 / 全班 +2），跨级还会置待演标记。看完后让我调一次 E2E 同款接口一键回滚，零污染：

```
POST /api/boss/reset
```

它会：撤回当日全部 BOSS 流水并回滚成长值/等级 → 清全班 evolve_pending → 删当日 boss/hit/内存会话。
（注：reset 只清**当天**；跨天残留需按日期另清。）

## 五、结论

- 逻辑链路（13 个功能点中 1~11）E2E 全自动覆盖，**2 passed (2.1m)**，真实学生数据零污染已 API 核对。
- 待老师手动过的只有 **13 号双屏 SSE 体感 + 动画 + 投影可读性**（第三节 10 步，约 15 分钟）。
- 与拔萝卜不同：打怪兽走**正常登录鉴权**、不要麦克风、**无需 HTTPS**，localhost 即可完整自测。
- 已知边界：当前题/答题人存内存 Map，后端重启会丢（重新出题即可，设计如此）；ESCAPED 为查询时懒判不落库。
