# 宠物园特效方案（v1.1 增强，纯前端）

> 2026-09-01 分析。v1 已交付（卡片呼吸浮动 + dizzy 紫色头晕 emoji），用户反馈"现在是晃动，想要更强表现"。
> 原则：不引 three.js/视频/lottie；90% CSS + emoji，爆发特效用 canvas-confetti（~6KB gzip，零依赖）。
> 设计参照：洛克王国/赛尔号升级、蛋仔派对反馈——小学生吃的是**夸张正反馈**；负反馈要温和（天气化，不伤害不羞辱）。

## 一、瞬间爆发特效（事件触发，1~3 秒）

| 事件 | 特效 |
|---|---|
| 手动加分 | 宠物头顶飘金色 `+N`（弹跳后上升淡出 1.2s）+ 2~3 个 ⭐✨ 迸溅；宠物 Q 弹（scale 1.1→0.95→1，0.4s） |
| 自动/手动扣分 | 飘灰红 `-N`；宠物缩一下（scale 0.95，0.3s）；头顶冒一滴汗 💦（2s 淡出） |
| **升级** | 卡片金色光柱（顶部射下 radial-gradient，1.5s 淡出）+ Lv 徽章"啵"弹跳 + 彩虹弧 🌈 浮现 + confetti 金/马卡龙色彩带从卡片两侧喷出；文案"XX 升到 Lv.N！🎉" |
| **毕业（最高潮）** | 全屏暗化聚焦该卡 → 金光白闪 2 次（⚡ emoji 同步闪，神兽进化感）→ confetti 三波连发 → 👑 皇冠从卡顶旋转落下停在宠物头上 1.5s → 🥇 徽章弹出入徽章墙 → 变回蛋态 |
| 成绩一键发奖 | 每个获奖学生卡飘 🏆+3/+2⭐；顶部浮动条"已奖励 N 名同学 🎉" |
| 商店兑换 | 🪙🪙🪙 三枚金币从宠物处蹦出（抛物线），宠物开心蹦跳 |
| 批量评价 | 每张被勾选卡片同时飘 +N⭐（错峰 0.1s 依次触发，像放小鞭炮） |

实现：飘字/emoji 用一个 `<FloatFx>` 小组件（事件时 push {emoji/text, x, y, color}，CSS 动画结束移除）；confetti 调 `canvas-confetti`，事件结束自动 stop。

## 三、常驻气场（身份感，低强度一直显示）

- 蛋态：光晕呼吸（v1 已有）
- Lv1~3：仅呼吸浮动
- Lv4：脚下淡金光环（conic-gradient 线性渐变圈，8s 一圈缓慢旋转，opacity 0.25）
- Lv5：光环加速（5s）+ 周身 3~5 个 ✨ 随机位置淡入淡出（2s 循环错峰）+ 卡片金色描边

## 四、不做什么

- 不做全屏/全卡常驻风雨雷电火（40 张卡视觉灾难 + 性能浪费）；⚡🔥 只在毕业/升级瞬间出现。
- 不做宠物表情切换（立绘固定，情绪全靠天气 emoji 叠加表达）。
- 不引 lottie/视频/WebGL。

## 五、性能

- 常驻动画仅 transform/opacity（GPU 合成层），40 卡无压力。
- confetti canvas 事件时创建、结束销毁；同屏最多一张卡爆发。
- 乌云雨滴/雪花用纯 CSS 动画，每卡 ≤3 个动画元素。

## 六、依赖

- `npm i canvas-confetti`（前端唯一新增依赖，~6KB gzip）。
- emoji 全部系统字体渲染，零素材。
