# 班级宠物园（游戏化积分激励）需求说明

## 背景与问题
- 参考原型：酷课堂「班级积分宠物园」（img/学生宠物系统/ 5 张截图）——学生领养宠物，老师日常评价加减成长值，宠物升级/毕业获徽章，积分可在小商店兑换实物奖励。
- 独立宠物系统的最大成本：老师要专门打开系统、手动点评价，难以坚持。
- 本平台的独特优势：考勤、作业、纪律、成绩、值日、速记每天都在登记——**这些登记可自动转化为成长值，"记录即评价"**，零额外操作；宠物形象还可融入花名册/座次表/档案抽屉，与奶油糖果马卡龙 UI 天然契合。

## 目标
1. 学生领养守护宠物（emoji 萌宠），通过成长值升级（Lv.1~5），满级毕业获徽章、可换新宠。
2. 评价体系：预置 ~35 个加减分评价项（学习/行为/健康/其他），支持单人评价、批量评价、撤回、流水记录。
3. **自动联动（核心差异点）**：考勤/作业/纪律/速记登记自动产生成长值变动；成绩导入后一键发放"进步奖/满分奖"。
4. 荣誉榜（排名+宠物+等级+徽章）；小商店（积分兑换实物，系统记账）。
5. 教育安全：荣誉榜只展示先进；扣分有保护（不降级、宠物不受伤害）；老师可关闭自动扣分。

## 非目标
- 不做宠物喂食/装扮/互动小游戏（v2）。
- 不做学生端/家长端登录查看（v2 可做教室大屏展示模式）。
- 小商店不涉及线上支付/真实物流，仅线下履约记账。
- ~~不使用宝可梦官方素材~~ → 已改 **CC0 正版 3D 素材**（Quaternius，可商用可入仓库，见素材方案），无版权风险。

## 需求范围

### A. 宠物与成长
- 未领养学生显示一颗 🥚（3D 神秘蛋，呼吸摇摆+光晕）+「领养精灵」；领养弹窗展示 **4 只 Lv1 3D 幼体**（丛林/海洋/神秘/森林四系，各一只实时 3D 预览），每只有中文名与属性系；选定后沿该系进化链进化。
- 进化链 6 阶段：**神秘蛋 → Lv1 可爱幼体 → Lv2 成长伙伴 → Lv3 成熟伙伴 → Lv4 完美精灵 → Lv5 传说神兽**；4 条链共 20 个形态（链/形态/中文名/模型映射见《资源清单.md》）。
- 宠物卡：海报静态图 + CSS 呼吸浮动（同屏 40 张卡不开 WebGL，避免上下文上限）、精灵名、Lv 徽章、成长值进度条（当前/本级阈值）、学生姓名；卡片马卡龙奶油风。
- **3D 实时渲染只用于**：领养弹窗预览、宠物详情弹窗、毕业仪式、档案抽屉宠物区（单例 WebGL 渲染器，关闭即 dispose；模型带 Idle 骨骼待机动画）。
- 升级曲线：Lv1→2 需 40，之后每级 +20（40/60/80/100），累计 280 成长值满级（Lv.5）。
- 满级后「毕业仪式」（3D 场景：Wave 动画+金色粒子）→ 获得毕业徽章（徽章墙）→ 可重新领养新宠物从 Lv.1 开始；徽章数进荣誉榜。
- 学生可更换宠物（毕业才能换；中途换宠成长值清零，二次确认）。
- **负面状态（短期，次日重置）**：扣分当日宠物"头晕眼花"（播 HitReact 动画+头顶星星）；成长值扣为负"冻结蛋"（临时变回蛋+冰蓝覆盖层）；单周累计扣 100+"蛋碎裂"（灰蛋+裂纹覆盖层+摇晃）。均为当日/当周临时表现，次日恢复，不降级、不永久伤害。

### B. 评价体系
- 评价项库（per-user，可增删改、可停用）：字段 {分类, 名称, 分值(±), emoji图标, 是否启用}。
- 预置项（参考原型，~35 项）：
  - 学习（+）：作业完成优秀+1、平时测验满分+3、测验达优秀线+2、默写全对+1、订正态度认真+1、优秀作业值得表扬+1、学习状态进步+1、被老师点名表扬+1、单元测验显著进步+2、早读认真专注+1、课前准备充分+1
  - 行为（+）：升旗安静整齐+1、守纪表现优秀+2、主动帮助同学+2、拾金不昧(一般)+2、拾金不昧(贵重)+5、帮助生病同学+3、调解同学矛盾+3、好人好事被校表扬+3、志愿服务+3、犯错主动认错+1、认真完成值日+1、主动擦黑板+1、整理讲台+1、倒垃圾+2、座位整洁+1、座位周围无垃圾+1、整理图书+2、眼保健操认真+1
  - 扣分项：作业未交-1、迟到-1、早退-1、缺勤-2、课堂违纪-2、吃零食/打闹-2、座位脏乱-1、忘记值日-2
- 操作：
  - 单人：点学生卡 → 评价弹窗（分类 tab + 项卡片网格，点项即生效）。
  - 批量：顶部「批量评价」→ 勾选多个学生 → 选项 → 一次生效（课堂场景：小组/全排奖励）。
  - 撤回：最近误操作一键撤回；评价记录流水（可按学生/日期筛选，单条撤销）。

### C. 自动联动（本平台杀手锏）
| 来源模块 | 触发 | 成长值 | 方式 |
|---|---|---|---|
| 早读考勤 | 登记"迟到" | -1 | 自动（可开关） |
| 早读考勤 | 登记"缺勤" | -2 | 自动（可开关） |
| 作业收缴 | 登记"未交" | -1 | 自动（可开关） |
| 课堂纪律 | 登记违纪 | -2 | 自动（可开关） |
| 一句话速记 | 解析落库考勤/作业/纪律 | 同上 | 随来源自动 |
| 成绩导入 | 测验满分/达优秀线/排名进步≥5 | +3/+2/+2 | **一键发放**（导入后弹出待发清单，老师勾选确认，避免误发） |
| 请假闭环 | 请假不扣分（与迟到区分） | 0 | — |
- 自动扣分设全局开关（设置项 pet_auto_deduct，默认开）；自动产生的流水 source 标 AUTO_*，撤回评价时只撤宠物分、不删业务记录。
- 请假/出勤等正常状态不加分不扣分；全勤/作业全交的周结奖励列 v2。

### D. 荣誉榜
- 弹窗：排名（前三名金🥇银🥈铜🥉奖牌 emoji）、学生、伙伴宠物名、等级、徽章数；按成长值总数排序。
- 只展示正向信息，不展示扣分明细；后 1/3 不显示排名（只显示等级），避免羞辱。

### E. 小商店
- 商品（per-user）：名称、emoji 图标、价格（成长值）、库存；管理商品增删改。
- 兑换：老师代操作（学生申请→老师兑现），扣成长值、扣库存、记兑换记录（待兑现/已兑现状态）。
- v1 可做最简版（商品+兑换+记录），库存可为空表示不限。

### F. 入口与融合
- 侧边栏新增模块「🐾 宠物园」（马卡龙橙色调）。
- 花名册学生卡角标显示宠物海报缩略图（或 emoji 兜底）+ Lv；学生档案抽屉新增"🐾 宠物"区（3D 形象/等级/徽章墙/最近评价流水）。
- 座次表卡面 v2 再考虑加宠物（v1 不加，避免信息过载）。

## 数据方案（全部 per-user，user_id 隔离）
- `pet`：id, user_id, student_id UNIQUE, pet_key(进化链标识 chain_a/b/c/d，形态由 level 推导：0=蛋 1~5=五阶), pet_name, level(默认1), exp(默认0), adopted_at, graduated_count(默认0)
- `pet_rule`：id, user_id, category(学习/行为/健康/其他), name, score INT, icon, enabled TINYINT, auto_source VARCHAR(32)（如 ATTENDANCE_LATE，空=纯手动）
- `pet_log`：id, user_id, student_id, rule_id NULL, score, source(MANUAL/AUTO_ATTENDANCE/AUTO_HOMEWORK/AUTO_DISCIPLINE/AUTO_SCORE), biz_ref(关联业务记录id), remark, created_at
- `pet_badge`：id, user_id, student_id, pet_key, pet_name, created_at（毕业徽章墙）
- `pet_shop_item`：id, user_id, name, icon, price, stock(-1=不限)
- `pet_exchange`：id, user_id, student_id, item_id, cost, status(待兑现/已兑现), created_at
- 设置项：pet_auto_deduct(默认1)；UserDataSeeder 为新账号播种预置评价项（全局模板？评价项 per-user 可改，种子进 seeder）。
- 升级/毕业逻辑在后端统一计算（加分后重算 level，满级不溢出）。

## 影响范围
- 后端：新增 PetController（宠物/评价/榜/商店/记录）；考勤/作业/纪律/速记/成绩导入处挂自动联动钩子（统一走 PetService.award(uid, studentId, ruleOrScore, source, bizRef)）；UserDataSeeder 加评价项种子。
- 前端：新增 views/PetGarden.vue（宠物卡网格+领养+评价+批量+荣誉榜+商店+记录，弹窗化）；路由/侧边栏入口；Roster 卡片与档案抽屉加宠物元素；Settings 加自动扣分开关。
- 数据迁移：新表幂等创建；老学生无宠物记录时前端显示 🥚 蛋，无需补数据。

## 验收标准
- 学生可领养 emoji 宠物；加分后成长值/进度条正确变化；达到阈值自动升级；满级可毕业获徽章并领养新宠。
- 单人评价、批量评价即时生效；撤回/撤销后成长值正确回退；流水可查。
- 自动联动：登记迟到/未交/违纪后对应学生宠物自动扣分（开关关闭时不扣）；成绩导入后一键发放清单，满分/优秀/进步学生与成绩数据一致。
- 请假记录不产生扣分。
- 荣誉榜排名正确、前三有奖牌、徽章数正确。
- 小商店：兑换扣积分扣库存、记录可查、库存不足/积分不足有提示。
- 多账号隔离：A 班宠物与评价 B 账号不可见。
- E2E：领养→手动加分→升级断言→批量评价→自动扣分联动→撤回回滚→兑换全链路。

## 已拍板决策（2026-09-01）
1. **扣分理念**：可扣分、**不降级**——成长值可被扣减但不为负、不掉级；宠物无"生病/死亡"负面状态；荣誉榜只展示正向信息。
2. **自动联动**：**登记即自动扣**（迟到/未交/违纪登记瞬间产生宠物扣分流水），设置页保留全局开关 pet_auto_deduct。
3. **v1 范围全量**：小商店 ✅、毕业徽章+换宠 ✅、花名册/档案融合 ✅、成绩一键发奖 ✅。
4. **宠物素材（2026-09-01 二次拍板，推翻 GIF 方案）**：**three.js 真 3D 方案**——Quaternius 正版 CC0 骨骼动画 GLB 模型（用户否定像素 GIF："你搞的太老了"，要"动的，3D 效果的"）。
5. **负面状态**：**短期状态次日重置**——扣分头晕次日恢复、积分负变冻结蛋、单周扣 100+ 蛋碎裂；不降级、不永久伤害。
