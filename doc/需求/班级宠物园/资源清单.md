## 来源与许可

- **作者**：Quaternius（https://poly.pizza/u/Quaternius ），3D 素材界知名 CC0 作者。
- **许可**：**CC0 / Public Domain**（poly.pizza 每个模型页标注 Public Domain）——可商用、可修改、**无需署名、可入 git 仓库**，无宝可梦 GIF 方案的版权风险。
- **格式**：glTF 2.0 二进制（.glb），低多边形柔光风，与奶油糖果马卡龙 UI 风格契合。
- **动画**：24 个生物模型全部带骨骼动画（7~30 个/只），均含待机动画（陆地系 `Idle`、飞行系 `Flying_Idle`），并白送状态动画：`HitReact/HitRecieve`（受击头晕）、`Jump/Dance`（升级庆祝）、`Wave`（毕业告别）、`Death`（备用）。
- 模型页（含预览/下载按钮）：`https://poly.pizza/m/{slug}`；GLB 直链：`https://static.poly.pizza/{uuid}.glb`（同 UUID 的 `.jpg` 为官方渲染海报图）。
- 本机已验证：poly.pizza 与 static.poly.pizza 国内直连可达（Cloudflare，间歇 SSL 重置需重试 2~6 次）。

## 前端技术要点（three.js）

1. **依赖**：`three` + `GLTFLoader`（npm i three，无额外加载器依赖；动画用内置 AnimationMixer）。
2. **动画名模糊匹配**（不同包命名不一致，勿写死）：
   - 待机：动画名含 `Idle`（优先精确 `Idle`/`Flying_Idle`，飞行系自带上下浮动）；
   - 升级庆祝：含 `Dance` 或 `Jump`；受击头晕：含 `Hit`；毕业：含 `Wave`。
3. **渲染策略（性能关键）**：宠物卡网格不用 WebGL——浏览器 WebGL 上下文上限约 16 个，40 张卡会爆。卡片用官方海报图（posters/*.jpg 复制到 public/pets/posters/）+ CSS 呼吸浮动；**3D 渲染只用于**：领养弹窗预览、宠物详情弹窗、毕业仪式、档案抽屉宠物区（单例渲染器，弹窗关闭即 dispose）。
4. **蛋**：egg.glb 无骨骼，待机用代码做轻微摇摆/旋转 + 底部光晕；孵化（领养）时播放放大+光粒子切换 Lv1 模型。
5. **负面状态（短期，次日重置）**：
   - 扣分当日"头晕眼花"：播 `HitReact` 动画 + 头顶转圈星星（CSS sprite 或 three 粒子）；
   - 成长值为负"冻结蛋"：临时切回蛋模型 + 冰蓝滤镜/冰柱 CSS 覆盖层；
   - 单周扣分 100+"蛋碎裂"：蛋模型染灰 + CSS 裂纹覆盖层 + 摇晃；
   - 满级光效/升级粒子用 three 粒子或 CSS 光效实现，不依赖模型素材。
6. 模型缩放/朝向以 GLB 自带坐标为准，前端按包围盒归一化到统一高度（如 1.8 单位），相机固定 3/4 侧面、可慢速 autoRotate。
