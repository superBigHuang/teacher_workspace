## 备档：3D 皮克斯风 + 图生视频方案（已简化弃用，留作参考）

## 生成流程（4 步）

1. **总览定风格**：用「总览 prompt」出一张 6 阶段进化序列图，挑风格。
2. **单体精修**：先文生图出 Lv1 定稿；Lv2~Lv6 用「垫图/角色参考」上传 Lv1（或前一阶）图 + 阶段描述 + 风格后缀，保证同一只生物进化感。
3. **抠图**：要纯白背景全身像；即梦自带抠图，或 remove.bg，输出透明 PNG。
4. **图生视频**：定稿图 → 图生视频（待机循环 3~5 秒）→ mp4；前端卡片用静态图 + CSS 呼吸浮动，详情/领养/毕业弹窗用 `<video autoplay loop muted playsinline>` 播视频（不可见时暂停，控制性能）。
