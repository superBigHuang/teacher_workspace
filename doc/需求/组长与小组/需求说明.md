# 列组长（小组长标识）

> 2026-09-02 分析定稿；**2026-09-03 已落地**（后端 + 前端 + E2E，见文末「落地结果」）。
> 关联：值日表·班委（committee）、座次表（座位/列）、成就系统（班委担当）。

## 背景与问题

- 班级按"列"分组管理（收作业、管纪律、带读），每列需要一个组长；组长由老师在**该列任意位置**指定（不一定是第一排那个学生）。
- 现在系统只有"班委"（班长/学习委员…），没有"组长"概念，座位上也看不出来谁是组长。

## 已确认决策

1. **组 = 座位的一"列"**（纵向一列学生为一组，第 1 列…第 N 列各一个组长）；不是按过道合并的大组。
2. 组长由老师在该列**任意座位**指派，不限第一排。
3. 本期**只做标识与展示**（👑角标 + 设/取消 + 班委/评语/成就复用）；不做小组积分、组长批量登记、自由学习小组。

## 现状事实（已核对代码）

- `committee(user_id, student_id, role)`：班委任职记录，role 自由文本；DutyController 已有 `GET /duty/committee`（返回 studentId/role/name）、`POST /duty/committee {studentId,role}`、`DELETE /duty/committee/{id}`；在 **Duty.vue（值日表·班委）** 页管理。
- 成就「班委担当」(COMMITTEE) 判定该生在 committee 有记录；评语素材取 committee 的 roles。
- `/seat/grid` 返回每座位 studentId/row/col/gender；换座/随机排座会改变学生所在列。

## 方案：复用班委表，组长 = role '组长'，列归属实时推导

### 数据（零表变更）

- **不新建表、不加列**：组长就是 committee 里一条 `role='组长'` 的记录。
- **不存"第几列"**：组长属于哪一列，实时由他**当前座位的 col** 推导（查 seat_assignment 该生所在列）。这样随机排座/换座后组长自动"跟人"到新列，**没有数据一致性要维护**。
- 一列至多一个组长：由"设组长"接口在后端保证（设新组长时，删掉同列已有的旧组长记录）。

### 怎么设/取消（后端，2 个轻接口，放 SeatController）

- `POST /api/seat/leader { studentId }`：
  1. 查该生当前座位（seat_assignment），拿到列 col；未排座 → 报错"请先安排座位"。
  2. 删该列**其他学生**的 `role='组长'` 记录（同列只留一个）。
  3. 若该生自己已是组长 → 视为取消（删除并返回 canceled）；否则 INSERT committee(student_id, role='组长')。
- `GET /api/seat/leaders`（或前端直接复用 `GET /duty/committee` 过滤 role='组长'）：返回当前所有组长 studentId 列表；前端结合 seats 即可知道每列组长是谁。
  - KISS：前端座次页 onMounted 并行拉 `/duty/committee`，过滤 role='组长' 得 studentId 集合即可，**可不加 GET 接口**；设/取消用上面 POST 一个接口（内部含取消与替换）。

### 放在哪里管理（主入口：座次表页）

- 工具栏加一个开关按钮 **「👑 组长」**（类似"批量评价"那种模式开关）：
  - 开启后进入"指派模式"：点任意座位 → 调 `/seat/leader`；该生非组长则设为其所在列组长（同列旧组长自动被替换），已是组长则取消。
  - 指派模式下可给个轻提示"点座位设为该列组长，再点取消"。
  - 关闭后恢复正常（点座位开宠物详情）。
- 班委页（值日表·班委）：组长自动出现在班委名单（role='组长'），可正常移除；可选择把"组长"与其他班委分组显示（可选美化）。

### 在哪里展示

- **座位卡**：组长学生顶部加 **👑 角标**（与 🎓毕业角标、🏅奖牌同类，放座位卡顶部角标区）。
  - 座位设置「显示」区加"组长👑"勾选，存 `seat_display.fields.leader`（**默认开**，老偏好缺省按默认）；简易模式随装饰整块隐藏。
  - **打印座次表带 👑**（建议：贴讲台/代课老师看谁是组长很有用）——打印区在姓名旁加 👑，受同一个显示开关控制。
- **花名册 / 学生档案 / 评语**：职务素材自动含"组长"（复用 committee）；成就「班委担当」组长自动满足。

### 边界与规则

- 未排座学生不能设组长（没列）；清空座次后组长记录保留（人还是组长），重新排座后 👑 跟人回到所在列。
- 随机排座后，组长们散到各列、👑 跟人；可能出现某列暂无组长或一列两位（换座导致），老师进指派模式微调即可——本期不做"自动保证每列一个"。
- 组长是学生属性（跟人），不是固定列位；这与"老师安排谁当组长"一致。

## 影响范围

- **后端**：SeatController 加 `POST /seat/leader`（含同列替换/取消逻辑，查 seat_assignment + committee）；**schema 零变更**。DutyController/committee 不动。
- **前端**：Seat.vue 加「👑组长」指派模式 + 座位卡👑角标 + `seat_display.fields.leader` 开关（默认 1）+ 拉 committee 组长集合 + 打印区带👑；Duty.vue 班委名单自然显示组长（可选分组美化）。
- **数据**：零迁移；老 committee 记录无 role='组长'，即暂无组长，符合预期。

## 验收标准

1. 「👑组长」模式下点某列**中间**一个座位 → 该生成为组长、座位卡显 👑；同列若已有组长，旧组长 👑 消失（自动替换）；再点该组长 → 取消。
2. 未排座学生点设组长给出提示；每列至多 1 个组长。
3. 换座 / 随机排座后 👑 跟人移动（组长还是那些学生）；刷新后保留。
4. 组长出现在值日表·班委名单；学生评语职务含"组长"；满足「班委担当」成就。
5. 座位设置"组长👑"开关可隐/显；简易模式隐藏；打印座次表带 👑；`npm run build` + E2E 通过、admin 真实数据无污染。

## 未来演进：组员与小组 PK（本期不做，预留钩子）

- **本期"组员"是隐式的**：同列学生即该组组员（按 seat_assignment.col_no 实时算，不落库）；组长显式存于 committee（role='组长'，挂学生）。标识展示够用。
- **为什么 PK 阶段要升级**：小组 PK 需要一批学生**稳定绑定、累计组积分**，而座位会随机排/手动换——组若永远等于"当前列"，换座即洗牌、积分无处归属。
- **未来数据模型（PK 立项再加，本期不建）**：
  - `study_group`（id / user_id / class_id / name"第N组" / **leader_id 组长学生id** / created_at）；
  - `study_group_member`（id / group_id / student_id，uk(group_id,student_id)）；
  - 组积分：评价/考勤/作业/宠物成长按组员聚合到组（组积分流水或实时聚合），做组间排行 PK；
  - 组与座位**解耦**：组是学生集合，排座可"按组排一列"但换座不洗掉组归属。
- **本期为未来留的钩子（零额外成本）**：
  1. 组长挂在**学生**上（committee role='组长'），未来直接当 `study_group.leader_id`，无需迁移；
  2. 未来提供"**按当前座位列一键建组**"：每列建成一组、该列现有组长当 leader、同列学生入 member，把现在的列分组几秒导入显式组表，再手动微调；
  3. 本期不提前建组表/成员表（KISS，避免过度设计）。

## 待开工确认（小点）

## 落地结果（2026-09-03，已实现）

两个待确认小点均按推荐落地：打印**带** 👑；交互用**工具栏「👑 组长」模式开关 + 点座位**。

### 后端（SeatController，schema 零变更）

- 新增 `POST /api/seat/leader { studentId }`：
  1. 查该生当前座位（seat_assignment）拿列 `col_no`；未排座 → `Result.fail("请先给该生安排座位")`。
  2. 该生已是 `committee role='组长'` → 删除并返回 `{canceled:true}`（取消）。
  3. 否则先**删同列所有学生**的 `role='组长'` 记录（保证一列一个），再 INSERT，返回 `{canceled:false, col}`。
- 组长集合查询**不加新接口**：前端复用 `GET /duty/committee` 过滤 `role='组长'`。
- 组长自动进班委名单、评语职务素材（TermStatsService）、「班委担当」成就（AchievementScanner），均零改动复用。

### 前端（Seat.vue）

- 工具栏加「👑 组长」模式按钮：开启变"✅ 完成指派"，进入指派模式；与「📝 批量评价」**双向互斥**（开一关另一），指派模式下座位 `:draggable=false` 禁拖拽；提示条引导。
- `onSeatUp` 最前面加指派分支（位移阈值/有学生之后、简易模式 return 与宠物弹窗之前）：指派模式点座位 → `POST /seat/leader`；成功 ElMessage 提示"已设为第 N 列组长 👑"/"已取消组长"并重拉组长集合；后端 fail（未排座）由 http 拦截器弹消息。
- 组长状态：`leaderIds = ref(new Set())` + `loadLeaders()`（拉 /duty/committee 过滤组长，失败静默）+ `isLeader(sid)`；onMounted 与指派成功后刷新。
- 👑 角标 `.seat-leader` 放 **.seat-pet 块外**（与 .seat-name 同层）→ **简易模式常驻**；右上角绝对定位、z-index:6（高于宠物4/天气5）、pointer-events:none；受 `disp.fields.leader` 开关控制（默认开）。
- 打印区姓名旁加 `.print-leader` 👑（同一开关控制）；预览缩略图不加。
- 显示偏好：`dispDefault.fields.leader=1`、`FIELD_KEYS` 加 `'leader'`、设置弹窗加「👑 组长」勾选；老偏好缺省分层兜底默认 1。

### E2E（e2e.spec.js 步骤 14）

### 追加迭代（2026-09-03）：值日页「学习小组」分区

用户反馈：组长混在「🎖️ 班委名单」标签里看不出组结构。调整（**纯前端 Duty.vue，零接口变更**）：

- 班委名单标签**过滤掉** `role='组长'`（数据仍在 committee，评语职务/成就复用不受影响）；「添加班委」职务下拉移除「组长」（组长统一在座次表按列指派）。
- 班委名单卡下方新增 **「👑 学习小组」卡片区**：
  - 按座位列每列一张彩色卡（配色复用值日卡五色 `dayColors` 循环），标题「第 N 列」；
  - 组长行 👑姓名 金色底高亮、可 × 移除（调既有 DELETE /duty/committee/{id}）；
  - 其余同列学生列为组员（按排次排序）；无组长列显示"暂无组长"；
  - 未排座组长（清空座次后记录保留）灰色「未排座」卡兜底，重新排座自动归列。
- 数据：Duty 页 onLoad 并行拉 `GET /seat/grid`，按 col 分组 + committee 组长记录实时计算，不存组关系。
- E2E：步骤 14.8 断言班委标签区无"组长"、小组卡数=有学生的列数、组长落在对应列卡且组员行存在；步骤开头先清组长残留保证幂等。
