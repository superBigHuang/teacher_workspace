# 座次表：设置收纳 · 简易模式 · 打印倒转 —— 需求说明

> 2026-09-02。来源：座次表页实际使用反馈（截图）。状态：**已实施完成（2026-09-02），build 通过、E2E 全绿**。

## 背景与问题

1. **工具栏过道控件错位**：现状模板把 `过道1 过道2 过道3` 三个文字标签用 v-for 先循环完，再渲染三个下拉框，视觉上变成 `过道1 过道2 过道3 [第1列后▼] [第4列后▼] [第6列后▼]`——标签与下拉分离，看不出谁对应谁；加上行数/列数共 7 个控件挤在工具栏。
2. **无简易模式**：部分老师（或代课老师）只需要看座位位置，宠物图/天气特效/光环信息过载。
3. **不能打印**：座次表没有打印功能；打印平铺讲台上使用时，屏幕视角（讲台在上）与老师低头看纸的视角差 180°，需要"倒转"。
4. **卡面信息不可配**：名字固定竖排贴左，学号不显示；老师想选显示字段和名字位置。

## 目标

1. 工具栏瘦身：行数/列数/过道收进「⚙ 座位设置」弹窗，过道标签与下拉配对。
2. 「简易模式」一键切换：纯座位表，无宠物无特效。
3. 显示项可配：姓名/学号/性别符号/Lv 徽章/毕业角标/行列标签/未排座区显隐；名字位置三选一。
4. 打印：🖨 打印弹窗带预览，支持**倒转 180°（平铺讲台视角）**、黑白省墨、附未排座名单。

## 非目标

- 不改座位数据结构、拖拽换座、随机排座逻辑。
- 不做座位卡大小/密度自定义（留 v2）。
- 不做导出 PDF/图片（浏览器打印另存 PDF 已覆盖）。

## 方案

### 一、工具栏改造

- 工具栏移除：行数、列数、过道1/2/3 共 7 个控件。
- 新增两个按钮：`⚙ 设置`、`🖨 打印`；其余按钮（随机排座/清空/荣誉榜/小商店/评价项/批量评价）不动。
- **⚙ 座位设置弹窗**分区：
  - 布局：行数、列数（el-input-number，即时保存逻辑同现 saveConfig）；
  - 过道：三行配对排列 `过道1 [第N列后▼]`、`过道2 [...]`、`过道3 [...]`（选项：无/第1~N列后）；
  - 显示：简易模式开关 + 字段勾选 + 名字位置（见下）；
  - 改完即时保存（现有 `/seat/config` + 新增显示偏好）。

### 二、显示设置（账号级偏好，存 setting 表）

- 偏好 JSON 存 setting 表 key=`seat_display`（复用 `GET/POST /api/settings`，per-user，多设备同步）：
  ```json
  { "simple": 0,
    "fields": { "stuNo": 0, "gender": 1, "lv": 1, "badge": 1, "colLabel": 1, "unseated": 1 },
    "namePos": "v-left",
    "print": { "flip": 0, "mono": 0, "withUnseated": 1 } }
  ```
- **简易模式开关**（显眼，置顶）：开启 = 宠物图/天气特效/光环/Lv/毕业角标全部隐藏，未排座区宠物卡简化为纯名单网格；默认名字位置切为横排居中（可再改）。关闭恢复。
- **字段勾选**（简易模式关时细调）：☑性别符号底色（男蓝女粉，关了统一白底）、☐学号（跟在名字旁/下）、☑Lv 徽章、☑毕业 🎓 角标、☑行列标签（第X排/第X列）、☑未排座学生区。
- **名字位置**三选一（座位卡布局）：
  | 值 | 布局 | 适用 |
  |---|---|---|
  | `v-left` | 竖排贴格子左侧（现状），宠物大图占右侧 | 宠物园模式默认 |
  | `h-center` | 姓名横排居中大字，宠物小图在名字下方（无宠物时纯名字居中） | 简易模式默认、经典座位表 |
  | `h-bottom` | 宠物在上，姓名横排贴卡片底部 | 想突出宠物时 |
- 座位卡用 `:class="namePos"` 切换布局，CSS 控制，不改数据。

### 三、打印

- **🖨 打印弹窗**：左侧选项、右侧实时预览（按比例渲染同款棋盘，选项变化即时反映）。
- 选项：
  - **视角倒转**开关（默认关）：
    - 关 = 屏幕视角（讲台在上），用于存档、张贴墙上；
    - 开 = **倒转 180°**（讲台在下）：打印纸平铺讲台上、老师低头看时方位与教室一致、名字正向可读（屏幕视角=老师站讲台面学生；纸平铺讲台后近边=讲台侧，画面需转 180°，转后字顶朝纸远边，低头读为正字）。
  - **黑白省墨**开关：去掉性别粉底/蓝底、奶油背景，卡片黑框白底。
  - **附未排座名单**开关：打印页末尾附未排座学生姓名列表。
  - 打印内容跟随显示设置（简易模式打印出来就是纯座位表）。
- 实现：
  - Seat.vue 内加 `.seat-print-area` 打印容器（讲台+棋盘+可选名单，黑白/倒转 class 控制）；
  - 全局 CSS（theme.css 或新 print.css）：`@media print` 下 `body.seat-printing` 隐藏侧边栏/顶栏/工具栏/弹窗，只显示打印区；`@page { size: landscape; margin: 10mm; }`；
  - 倒转：`.seat-print-area.flip .print-board { transform: rotate(180deg); }`；
  - 点「打印」→ body 加 class → `window.print()` → 打印结束移除 class（afterprint 事件）。

## 影响范围

- 前端：`views/Seat.vue`（工具栏、两个弹窗、打印区、卡面布局 class）；新增少量全局打印 CSS；`composables/usePets.js` 不动（简易模式仅 Seat 视图层隐藏）。
- 后端：无表结构变更；显示偏好走现有 `/api/settings`（SettingsController 加 seat_display 键透传即可，或前端直接通用 k/v）。
- 数据：座位布局仍走 `/seat/config`；老用户无偏好时默认值=现状（宠物模式、竖排名）。

## 验收标准

1. 工具栏无行数/列数/过道控件；⚙ 弹窗内过道与下拉一一对应，修改后棋盘过道位置正确、刷新保留。
2. 简易模式开启：座位卡只显示姓名（+勾选的学号/性别），无宠物图/☁️/❄️/光环/Lv；未排座区变纯名单；刷新后保持。
3. 名字位置三种布局切换正确，竖排/横排文字不溢出卡片。
4. 打印弹窗预览与实际打印一致：倒转后讲台在下方、文字正向；黑白模式无彩色底；未排座名单随开关出现/消失。
5. E2E：设置弹窗改行数/过道保存生效；简易模式切换后座位卡无 img 宠物元素；打印区 DOM 存在且 flip class 切换正确（不实测浏览器打印）。

1. 行数/列数/过道收进 ⚙ 座位设置弹窗，过道标签与下拉配对。
2. 打印做整页 180° 旋转；打印弹窗内带**预览简图**（迷你棋盘随开关 rotate 180° 示意讲台方位）。

## 技术调研与实施要点（2026-09-02 开发前核对，任务书与现网代码的出入以此为准）

### 1. 后端设置端点（任务书表述需修正）
- 任务书写 `GET/POST /api/settings`，**实际端点是 `GET/PUT /api/settings/profile`**（`SettingsController`）。
- `GET /settings/profile` 已把 setting 表该用户全部 k/v 平铺返回（`SELECT k,v FROM setting WHERE user_id=?` forEach put）——seat_display 存了即自动带出，**GET 侧零改动**，前端读 `data.seat_display`（JSON 字符串，parse 失败用默认值）。
- **坑**：`PUT /settings/profile` 会 `UPDATE sys_user SET display_name=?, email=?, school=?`——Seat.vue 若只传 `{seatDisplay}`，`str(null)=""` 会把教师姓名/邮箱/学校**清空**。且显示偏好 watch deep 即时存，每次都 UPDATE sys_user 也不合理。
- **结论（决策 A）**：后端新增专用端点 `PUT /api/settings/seat-display`，body 接 `{v: "<json>"}`（或直接接对象后序列化为 JSON 字符串），只调 `upsertSetting(uid, "seat_display", v)`，不碰 sys_user。前端 onMounted GET profile 读、变更时 PUT 专用端点。

### 2. 打印 CSS 选择器（按 MainLayout 实际 class）
- MainLayout 结构：`.layout` > `aside.sidebar` + `main.content`（router-view 在内）；**无顶栏 header**。
- `@media print` 隐藏清单（任务书的 `.app-sidebar/.app-header` 改为实际 class）：
  `body.seat-printing .sidebar, .page-toolbar, .legend, .podium, .board-grid, .unseat-wrap, .batch-bar, .el-overlay, .el-message { display:none !important }`；
  `body.seat-printing .seat-print-area { display:block }`；`@page { size: landscape; margin: 10mm }`。
- 全局打印 CSS 不能放 Seat.vue `<style scoped>`（管不到 body class/@page），追加到 `frontend/src/assets/theme.css` 末尾（KISS，不新增文件）。

### 3. 数据字段
- `/seat/grid` 返回座位已含 `stuNo`（SeatController grid join `student.stu_no`）；打印区与学号显示座位侧直接可用。
- 未排座名单来自 `/pet/pets` 行（unSeatedPets）；其 stuNo 字段开发时先验证，缺失则名单/卡片学号降级为只显姓名（fields.stuNo 本就是可选项）。

### 4. 名字位置三布局（纯 CSS 切换，座位格加 `:class="effNamePos"`）
- 现状：`.seat` flex 居中；`.seat-name-v` 绝对定位竖排贴左（writing-mode vertical-rl）；`.seat-pet-img` 96px。
- `v-left`=现状；`h-center`=flex-direction:column，姓名横排居中加粗、宠物图缩小（~64px）在名字下方，无宠物时姓名垂直水平居中；`h-bottom`=column，宠物在上、姓名横排贴底居中。
- 模板 `.seat-name-v` 改名 `.seat-name`（学号小字 `.seat-stuno` 跟在姓名旁/下），三种布局全部由父 class 控制。
- **简易模式名字位置（决策 B，纯视图层不写回偏好）**：`effNamePos = computed(() => disp.simple && disp.namePos === 'v-left' ? 'h-center' : disp.namePos)`——开简易且用户没手动改过位置（仍是默认 v-left）才自动横排居中；用户选过 h-bottom 等则尊重；关简易自动还原 v-left。

### 5. 简易模式视图边界
- 座位格：不渲染 `.seat-pet` 整块（img/☁️❄️🌈光环✨🩹🎓/float 飘字全在其内，一个 v-if 收掉）；批量 checkbox 在 .seat-pet 外，保留；姓名按 effNamePos 布局，学号随 fields.stuNo。
- 未排座区：简易模式渲染纯名单网格（小格：姓名+可选学号，无图/按钮/进度条），点击不弹宠物窗（onCardClick 在 simple 时直接 return）；`fields.unseated=0` 时整个区隐藏（非简易也生效）。
- 空座位：简易模式仍显示"— 空 —"？任务书只要求**打印**时空位不显示；屏幕简易模式保留空位占位（维持网格形状），维持现状 empty-seat 样式即可。

### 6. E2E 污染防控（决策 C）
- E2E 要改行数为 5、过道、显示偏好——**座次布局与偏好是老师真实持久化数据**：测试开始先 GET `/seat/config` 与 GET profile 存原值，afterAll 恢复 rows/cols/aisles 并 PUT seat_display 回默认 JSON（或删键）。
- 打印断言用 `page.emulateMedia({ media: 'print' })`：`.seat-print-area` 可见、`.print-empty` 为 visibility:hidden（boundingBox 占位但不可见——断言用 `toBeHidden()` 对 visibility:hidden 元素成立）、`.page-toolbar` 隐藏、`.seat-print-area.mono` class 存在（黑白默认开）；flip 开关断言 `.seat-print-area.flip`。
- 不实测 `window.print()`（浏览器原生对话框无法自动化），doPrint 只验 body class 增删与打印区 DOM。

### 7. 实施顺序建议
1. 后端：加 `PUT /settings/seat-display`（~15 行）；
2. Seat.vue：工具栏瘦身 + seatCfgDlg（布局/过道/显示三区）+ disp reactive 持久化；
3. 座位卡/未排座卡 disp 渲染 + 三种名字位置 CSS；
4. printDlg + 预览简图 + .seat-print-area + theme.css 打印段 + doPrint；
5. E2E 5 段 + build + 恢复逻辑。
- usePets.js / 宠物业务逻辑 / 拖拽 / 随机排座均不动；默认值必须等于现状。
