# 拔萝卜朗读游戏 —— 测试方案

> 2026-09-05。配套 `需求说明.md`（验收标准见第九节）。
> 策略：**自动化只测路由可达性；麦克风→音量→进度链路必须真机手动验收**（无头浏览器拿不到麦克风，模拟音频无意义）。

## 三、真机手动验收清单（localhost，约 15 分钟）

前置：`cd frontend && npm run dev`，浏览器开 `http://localhost:5173/radish`，用 **Chrome/Edge**。

### A. 授权与底噪（对应验收 1、7）

1. 打开页面：封面有🐰🥕浮动、"🎤 点击开始"按钮、历史纪录区。
2. 点开始：浏览器弹麦克风授权框 → 允许。
3. 进入"嘘…兔兔在听环境声音"测底噪 2 秒，进度条走完自动开始。
4. **异常分支**：授权框点"阻止" → 页面出现红字"需要麦克风权限才能玩，请点地址栏左侧小锁允许"，不白屏。
5. 拔掉麦克风/禁用麦克风再点开始 → 同样出红字提示。

### B. 音量联动（对应验收 2、3）

6. 不说话：音量条贴底、😴 表情、引导语提示大声读；兔子动作最慢（约 0.5 倍速）。
7. 正常说话：音量条涨到绿/黄段、🙂/😆 表情切换、兔子明显变快。
8. 大声朗读：音量条进红段、播放速率接近 2 倍速、进度条持续上涨。
9. **静音回退**：大声读到进度 60%+ 后闭嘴 3 秒 → 进度开始缓慢回退（约每秒 -1.8%），兔子变慢；回退到 30% 停住不再掉。
10. **连击**：持续大声读 5 秒 → 顶部出现 🔥 连击标记，进度涨速变 1.5 倍；闭嘴断连后 🔥 消失。
11. 拍桌子/吹麦猛吹一下：音量条不应长时间贴顶（平滑 + 底噪扣除生效），兔子不会一嗓子直接拔完。

### C. 拔出萝卜（对应验收 4）

12. 进度满 100%：切"拔出萝卜"视频，屏幕中央弹"第 N 根萝卜！🥕"大字（弹簧缩放）+ 金橙撒花。
13. 左下角萝卜计数 +1，新萝卜图标弹入。
14. 胜利视频播完自动回拔萝卜循环，进度归零开始下一根。
15. 第 5 根时文案变"🎉 5 连拔！"且撒花更密（里程碑）。
16. 进度条上 🚩 目标刻度位置正确（默认目标 8 根）；达标后追加一次大加花。

### D. 结束与战报（对应验收 5、6）

17. 点"结束早读"：切"感谢成片"视频，视频播完（或 10 秒兜底）弹出战报卡。
18. 战报内容核对：总根数、最响时刻（时间+百分比）、评语分档正确（0-2 兔兔还饿着 / 3-5 吃饱啦 / 6-8 声音洪亮 / 9+ 全校最响亮）。
19. 拔 0 根就结束：评语为最低档，不报错。
20. 战报后回封面/再来一局：刷新页面回 IDLE 封面，历史最佳根数显示且保留（localStorage `radish_record`）；破纪录时战报标"新纪录"。

### E. 倒计时

21. 设置里倒计时默认 15 分钟：顶部 ⏱ 倒数走动；到 0 自动进入结束流程（同点"结束早读"）。

## 四、参数标定（真实教室体感，重点）

三个常量在真机上大概率要微调，**右上角齿轮面板可直接调**（鼠标移到屏幕右上角停 1 秒出现，3 秒不动自动隐藏）：

| 参数 | 默认 | 怎么判断合不合适 | 调法 |
|---|---|---|---|
| 音量阈值 threshold | 0.15 | 安静时兔子完全不动；正常齐读应稳定超过阈值 | 空调响/班吵就调高；学生读了不动就调低 |
| 每根目标秒数 targetSec | 18 | 全班正常齐读，一根应在 15~20 秒拔出 | 太快没成就感调大；太累调小 |
| 倒计时 | 15 分钟 | 按早读时长 | 与早读课等长 |

循环接缝（代码常量 `LOOP_START=1.0 / LOOP_END=3.0`，齿轮里没有）：观察兔子动作在循环跳回瞬间**跳帧是否明显**。轻微可接受；明显的话报回来，改 `Radish.vue` 顶部两个常量（区间收窄或换 ping-pong 方案，需求说明 3.3 已备）。

齿轮里还有"测试麦克风"按钮：点后读 3 秒，显示采集到的最大音量，用来快速判阈值。

## 五、上线验证（部署后，约 10 分钟）

前置：域名备案通过 + `bash scripts/deploy/ssl.sh` 配好证书（部署手册 §7）。

1. `curl -I https://<域名>/radish` 返回 200。
2. 浏览器开 `https://<域名>/radish`，地址栏锁图标绿色。
3. 点开始：弹麦克风授权（**不是**红字报错）——这一步过了就说明 HTTPS 链路全通。
4. 教室大屏电脑完整走一遍第三节 B/C 段（大屏音量、后排可视距离）。
5. 视频素材加载：拔萝卜循环秒开（pull.mp4 5.4MB，预加载）；不出现视频裂图/卡死。

## 六、不测什么（明确排除）

- 不做音频模拟自动化：Web Audio 采集依赖真实设备，mock 出来的音量条不证明任何东西。
- 不做跨浏览器矩阵：只保 Chrome/Edge（教室大屏可控）；Safari/Firefox 遇到问题再说。
- 不做压力/并发：纯前端单页，无后端无数据库。
- 宠物联动、手机遥控、分组 PK 属 v2，不在本方案范围。
