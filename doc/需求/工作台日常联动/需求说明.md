# 工作台卡片 × 日常登记联动 + 我的课表 —— 需求说明

> 2026-09-03 分析，当日完成落地。
> 涉及 5 个点：①我的课表/今日课程只显示"我要上的课"；②早读考勤卡片列出异常学生；③课堂纪律卡片联动 + 违纪情况可输入下拉 + 卡片显示违纪学生；④作业收缴卡片联动 + 科目只选我教的 + 卡片显示未交学生。

## 现状事实（已核对代码）

- **课表数据**：`timetable` JOIN `subject`（subject 有 `teacher` 字段）。课程表格子显示 `subject.teacher`；老师把自己任教的科目 teacher 填成 **"我"**（截图：科学/班会/自习=我，语文=孙老师、数学=赵老师…）。
- **工作台 `/dashboard/stats`**（DashboardController）：
  - `todayCourses/todayRemaining/weekRemaining` 查的是**班主任班全班** timetable 节次（没按 teacher 过滤）→ 所以"今日课程 9 节"含别人教的课。
  - `attPresent/attTotal` 只给数字（异常数 = 迟到/请假/缺勤 COUNT），**不返回异常学生名单**。
  - `disciplineToday` = 今日 discipline_log 条数；`homeworkMissing` = 今日 homework_check 未交**人次**（一个学生多科未交算多条），均**无明细**。
- **前端工作台**（Dashboard.vue）：
  - "我的课表"卡 `loadTodayCourses()` 只拉**班主任班** `/timetable/grid`，cells 含 `subjectName/teacher/color`，显示全班课。
  - 三张登记卡（早读/纪律/作业）"点击登记"都是 `go('/daily')` —— **不带 tab**，而 Daily.vue `tab` 初始固定 `'att'`，所以点"课堂纪律/作业收缴"的登记都落到早读考勤页 → 这就是老师说的"**没连接到**"。
- **日常登记页**（Daily.vue）：
  - 课堂纪律：违纪情况是 `el-input` 纯自由文本（38 行），**无历史联想**；纪律列表 `disList` 来自 `/daily/discipline`（不带 date=全部记录）。
  - 作业收缴：科目下拉 `subjects` 来自 `/timetable/subjects`（**全部科目**：语文孙老师/数学赵老师/科学我…），没按"我教的"过滤。
  - tab 名：`att` / `dis` / `hw` / 请假。

## 方案（逐点）

### ① 我的课表 / 今日课程 → 只算"我教的课"
- **"我的课"判定**：`subject.teacher` 等于 **"我"** 或 **当前老师姓名**（displayName / setting teacher_name）。
- 后端 `/dashboard/stats`：todayCourses/todayRemaining/weekRemaining 改为 JOIN subject 且 `(sub.teacher='我' OR sub.teacher=?)`，只统计我教的节次。
- 前端 `loadTodayCourses()`：cells 同样按 teacher 过滤后再展示。
- **范围待确认（见下 Q1）**：只算班主任班，还是合并任课班（初一(2)班）里我教的节次。

### ② 早读考勤卡片 → 列出异常学生
- stats 增返 `attAbnormalList`：今日 `status IN ('迟到','请假','缺勤')` 的 `{name, status}`（JOIN student、限班主任班）。
- 卡片 body 在"今日全勤 39/40"下方列出异常学生：`姓名` + 状态彩色小标签（迟到黄/请假蓝/缺勤红），如"张三-缺勤"。全勤时显示"今日全勤 🎉"。

### ③ 课堂纪律联动 + 可输入下拉 + 卡片显示学生
- **联动**："点击登记"改跳 `/daily?tab=dis`；Daily.vue 挂载时读 `route.query.tab` 定位到对应 tab。
- **违纪情况改可输入下拉**：`el-select filterable allow-create`（单选），options = 历史 `disList` 里 `content` 去重（如"上课吃零食/讲话/睡觉"），可选历史也可直接打字回车输新内容；保存逻辑不变。
- **卡片显示学生**：stats 增返 `disciplineList`：今日 `{name, content}`；前端按学生**分组去重**，卡片 body 显示违纪学生姓名 tag（去重），**鼠标悬停** el-tooltip 列出该生当天全部违纪内容（多条全列）。标题"N 条"保留。

### ④ 作业收缴联动 + 科目只选我教的 + 卡片显示学生
- **联动**："点击登记"改跳 `/daily?tab=hw`。
- **科目下拉只留我教的**：`subjects` 过滤 `teacher==='我' || teacher===老师名`（作业收缴选我担任的科目，不再出现语文/数学等别人教的）。
- **卡片显示学生**：stats 增返 `homeworkList`：今日未交 `{name, subject}`；前端按学生分组，body 显示未交学生姓名 tag（去重），悬停列出该生今日**未交的科目**；标题"N 人未交"改为按**去重学生数**（现在是人次）。

## 影响范围
- 后端：`DashboardController.stats`（SQL 加 teacher 过滤 + 三个明细列表）；`DailyController` 基本不动（discipline/homework 接口已能返回数据，历史违纪 content 由前端从现有列表取）。
- 前端：`Dashboard.vue`（三卡 body 明细 + 跳转带 tab + 课表过滤）、`Daily.vue`（读 query.tab、违纪内容改 el-select allow-create、作业科目过滤）。
- 数据：无表变更。
- E2E：补充卡片明细断言、tab 跳转断言、作业科目过滤断言（用临时数据 + afterAll 清理，不污染 40 人）。

## 已确认决策（2026-09-03 拍板）
- **Q1：合并所有班级** —— 今日"我要上的课"= 班主任班 + 任课班里 `teacher='我' 或 =老师名` 的节次跨班合并（数字与明细都按此）。
- **Q2：作业科目保留班会/自习** —— 下拉只过滤 teacher=我，不按名字排除非学科，老师登记时自选。

## 验收标准
1. 工作台"我的课表/今日课程"只出现老师自己教的课（科学等），数字=我教的节数，别人教的语文数学不出现。
2. 早读考勤卡片能看到今天迟到/请假/缺勤的学生姓名和状态；全勤时提示全勤。
3. 工作台点课堂纪律/作业收缴的"点击登记"，直接打开对应 tab。
4. 课堂纪律登记违纪情况可从历史记录选、也可手打新内容；工作台纪律卡显示违纪学生姓名，悬停看当天全部违纪。
5. 作业收缴科目下拉只有我教的科目；作业卡显示未交学生姓名，悬停看未交科目，"N 人"按去重学生算。

## 落地结果（2026-09-03 完成）

- **后端 `DashboardController.stats`**：
  - 老师名取 `setting.teacher_name`，兜底 `sys_user.display_name`（空串用 `___NOMATCH___` 防误匹配 teacher='' 的科目）。
  - 今日课程/今日剩余/本周剩余：SQL 改为 JOIN subject、**跨所有班级**（去掉 class_id 过滤）、`(s.teacher='我' OR s.teacher=?)`。
  - 新增 `attAbnormalList`（{name,status}，限班主任班，迟到/请假/缺勤）、`disciplineList`（{name,content}）、`homeworkList`（{name,subject}，仅未交）；`homeworkMissing` 改 `COUNT(DISTINCT student_id)`。
- **前端 `Dashboard.vue`**：
  - `loadTodayCourses()` 改为拉**所有班级** grid 合并 cells，按 `teacher==='我' || ===settings.teacher_name` 过滤；"我的课表"与"今日课程"两卡共用此数据。
  - 三卡 body 改学生 tag 区：早读 `姓名-状态`（缺勤红/迟到黄/请假蓝）；纪律/作业按姓名**分组去重**显示 tag，el-tooltip 悬停列出该生当天全部违纪内容/未交科目；超过 10 人显示"等 N 人"；无数据显示全勤/无违纪/全部收齐。
  - 纪律/作业卡"点击登记"与整卡点击改跳 `/daily?tab=dis` / `/daily?tab=hw`。
- **前端 `Daily.vue`**：
  - 挂载读 `route.query.tab`（att/dis/hw/leave 合法值，否则 att）。
  - 违纪情况 `el-input` → `el-select filterable allow-create default-first-option`，options=历史 `disList` 的 content 去重；可手输新值回车创建，保存后自动进历史。
  - 作业科目下拉改 `mySubjects` computed：`!teacher || teacher==='我' || teacher===老师名`（未填教师的科目保留，不拦截）；老师名来自 `/dashboard/settings`。
- **E2E**（步骤 11c，针对临时 E2E测试生 + E2E 专用科目名，afterAll 删学生级联清理零污染）：
  - API：`/daily/homework/save`（科目 `E2E作业科目`，避免 save 按日期+科目整组重写误伤真实记录）→ stats 三名单含测试生、homeworkMissing 去重人数。
  - UI：三卡可见测试生 tag；悬停纪律 tag 出 tooltip（含"上课说话"）；点登记断言 URL `?tab=dis/hw` 且对应页签激活。
  - Daily：作业科目下拉"我教的都在、别人教的不在"；违纪下拉含历史"上课说话"，手输 `E2E违纪新情况XYZ` 登记成功且进历史。
- 构建：后端 mvn package 通过、已重启 8088；前端 npm build 通过。
