# 蛋点击详情交互 — 需求说明

## 一、背景与问题

座次表宠物卡片点击行为不一致：点击已破壳动物弹出宠物详情弹窗（头像/等级/经验进度条/成长流水/评价入口），但点击孵化中的蛋只弹一条 ElMessage 提示「还在蛋里攒能量」，老师看不到这颗蛋的孵化进度（当前 x/20 成长值）与成长流水，信息不对等。

## 二、目标与非目标

**目标**

- 点击孵化中的蛋与点击破壳动物一致：打开同一个宠物详情弹窗。
- 蛋态详情内已有孵化进度条（exp/20）与成长流水，直接复用，不新增 UI。
- 保留点击蛋时的左右摇晃反馈（eggWiggle 0.5s）。

**非目标**

- 不改详情弹窗本身（蛋态标题/孵化提示/进度条/流水/评价按钮均已内置）。
- 不改孵化规则（HATCH_EXP=20、攒够破壳逻辑不变）。
- 不影响批量模式（勾选）、未领养（领养弹窗）两条既有分支。

## 三、改动范围

- `frontend/src/composables/usePets.js`：`onCardClick` 移除蛋的 ElMessage 分支，统一走 `openDetail(p)`；蛋态先触发 eggWiggle 摇晃再开窗；删除已无引用的 `wiggleEgg` 函数。
- `e2e/tests/e2e.spec.js`：点击蛋断言从「ElMessage 提示攒能量」改为「详情弹窗可见、唯一遮罩、含孵化进度文案、Escape 可关」。

## 四、验收标准

1. 座次表/未排座区点击孵化中蛋：弹宠物详情窗，标题含「孵化中」，显示孵化进度（x/20 成长值）与成长流水。
2. 点击瞬间蛋仍有摇晃动画反馈。
3. 点击破壳动物、未领养空位、批量模式勾选行为不变。
4. 全量 E2E 通过。

## 五、待确认问题

- 无。

## 六、落地结果

- 全量 E2E（playwright，单用例 1 passed，约 1.8 分钟）通过：
  - 点击孵化中蛋：详情弹窗可见、唯一可见遮罩、标题含「孵化中」、含「成长值就破壳」孵化进度文案、Escape 可关闭。
  - 点击破壳动物详情、未领养走领养弹窗、批量勾选等既有行为不受影响。
- 已知外部问题（与本需求无关）：`/ai/test` 外部中转站渠道仍 ok=false，E2E 期间曾临时 try/catch 放宽、跑完已恢复严格断言（Grep 验证无「临时放行」残留）。需老师检查中转站模型渠道配置。
