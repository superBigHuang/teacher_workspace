# 家长联系方式 Excel 导入 + 设置页卡片紧凑布局 —— 需求说明

> 2026-09-03。两块：①家长联系方式页加 Excel 导入（主）；②设置页"豆腐块"松散修复。

## 背景与问题

1. 花名册已有 Excel 导入/导出（含父亲/母亲/电话列），但**家长联系方式页没有导入入口**；老师拿到的家长电话表想批量补录时，只能在花名册导入——而花名册导入对**已存在学号是跳过**（`/roster/import` 只新增学生），已在花名册里的学生补不进家长电话，只能逐条点编辑。
2. 设置页卡片高度参差：grid 两列同一行被最高卡片撑开，矮卡片下方大片空隙，"豆腐块不是紧挨着"，显乱。

## 目标与非目标

- 目标：家长页一键导入 Excel，按**学号**匹配已有学生并**更新**家长姓名/电话/住址；导入结果给出"更新 N 人、学号未找到 M 人"反馈。
- 目标：设置页卡片紧凑排列、视觉紧挨。
- 非目标：不做家长信息导出（花名册导出已含全部家长字段，可直接用它当模板）；不新增其他亲属关系导入（仅父亲/母亲，与现有模型一致）。

## 方案结论

### ① 家长导入（后端新增，前端薄接线）

- **后端 `CommController` 加 `POST /api/parent/import`**（multipart file，POI WorkbookFactory 自动识别 xls/xlsx）：
  - 表头：`学号 / 住址 / 父亲 / 父亲电话 / 母亲 / 母亲电话`（姓名列仅给老师核对，不参与匹配）。
  - 逐行按 `user_id + stu_no` 找学生：找不到 → `notFound++`；找到 → 住址非空则 UPDATE student；父亲/母亲按 `(学生,关系)` **upsert** parent_contact（有则更新 name/phone，无则插入；姓名电话全空跳过）；`updated++`。
  - 返回 `{updated, notFound}`。
- **前端 Parent.vue**：工具栏加 el-upload「📥 导入家长」按钮（照抄花名册导入模式），el-tooltip 说明表头与"可直接用花名册导出的 Excel 补电话后导回"；成功提示 `更新 N 人，学号未找到 M 人` 并刷新通讯录。
- 与花名册导入的区别：花名册导入=新增学生（学号重复跳过）；家长导入=**按学号更新**已有学生的家长信息，不新建学生。

### ② 设置页布局

- `.cards` 从 `display:grid` 改为 **CSS columns 两列瀑布流**（`columns:2; column-gap:18px`，卡片 `break-inside:avoid; margin-bottom:18px`）：卡片按自身高度流式排列，列内紧挨、无同行撑开的大空隙。
- 消息推送卡从 `grid-column:1/-1` 改为 `column-span:all` 跨两列；≤860px 单列。

## 影响范围

- 后端：`CommController.java`（新增 /parent/import + upsertParent/cell/getString 辅助）。
- 前端：`Parent.vue`（导入按钮）、`Settings.vue`（.cards 瀑布流）。
- 数据：无表变更；只 UPDATE/INSERT student.address 与 parent_contact。
- E2E：家长导入 API 全链路（xlsx 构造→导入→断言 updated/notFound→通讯录验证电话，针对临时学生 E2E测试生，删学生级联清 parent_contact 零污染）；家长页导入按钮可见；设置断言改为 columnCount=2。

## 验收标准

1. 家长页点「导入家长」选 xlsx：已有学号的父母电话/住址被更新，结果提示"更新 N 人，学号未找到 M 人"。
2. Excel 里不存在的学号计入"未找到"，不报错、不建学生。
3. 花名册导出的 Excel 补电话后直接导回可用。
4. 设置页卡片两列紧凑排列，消息推送卡仍跨整行；窄屏单列。
