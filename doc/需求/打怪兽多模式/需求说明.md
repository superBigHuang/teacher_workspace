# 打怪兽多模式 · 场次化改造 — 需求说明

> 基线文档：保留当前有效结论 + 最近进展。历史细节见 git 提交。

## 一、背景与问题

打怪兽原为「每天一只怪、手机/大屏手动 出题→抽人→判定」的单场玩法，老师提出 6 点改进：

1. 已选怪兽不能中途取消/结束；进入应能**新建**或**进入已创建场**，结束场可看**日志报告**。
2. 新增**随机 / 班级 / 小组 / 点名**四模式；新建时选模式、标题（默认带出可改）、可选题库；选了题库进页面**自动出题**，判定后**自动切题**。
3. 支持**无题库抽背**（老师口头布置背课文）；答对自动切学生（点名模式除外）。
4. 随机模式答对答错都自动切人、答对加分；小组模式以组为单位轮答、结束组排名，**前两组每个组员额外加分**；班级模式挨个答题，**整轮全对**生成「团结就是力量」成就（可累计升级）。
5. 答题时显示该生携带的**宠物飞出去攻击怪兽**。
6. 击败怪兽全班加分；选好模式后**按人数算怪兽血量，不能马上被击杀**。

## 二、目标与非目标

**目标**
- 场次化：一天可多场；大厅新建/继续/看报告；进行中场不可误删。
- 四模式自动流转：自动出题/抽题、自动切人；支持抽背（无题）。
- 血量按模式人数自动计算，答错不扣血 ⇒ 打不满一轮不会被秒。
- 奖励层：通关加分、击杀者加分、全班同庆、小组前二组员加分、班级整轮全对触发可进阶成就。
- 大屏宠物飞行动画。

**非目标（本期不做）**
- 不做场次删除/取消接口（进行中不可删；reset 仅供 E2E 自清理）。
- 不建独立小组表——小组 = 座位表的列（`seat_assignment.col_no`）。
- 手机 /m 旧流程仅保持兼容（无 mode 走 RANDOM 幂等），不重写手机端 UI。

## 三、已确认决策

| # | 决策 |
|---|---|
| 1 | 一天可多场（场次化），去掉「每天一只」唯一约束 |
| 2 | 血量按模式人数自动算：`hp_total = target_rounds × hit_per_pass` |
| 3 | 班级模式答错不中断，整轮（全班 N 人）全对才得团结成就 |
| 4 | 小组 = 座位表的列（`seat_assignment.col_no`），不建独立组表 |

## 四、需求范围 / 影响范围

**数据模型**
- `daily_boss` 升级为场次表：去 `uk_boss(user_id,boss_date)` 唯一键，改普通索引 `idx_boss_user_date`；新增 `mode/title/category_id/difficulty/round_no/target_rounds/ended_at`。
- `boss_hit` 新增 `round_no`、`group_col`；`quiz_id` 允许 NULL（抽背无题）。
- 迁移走 `DataInitializer` 幂等 `ensureColumn` + `rebuildBossIndex()`，老库重启自动生效。
- 新增内置成就「团结就是力量」（`rule_type=CLASS_UNITY`，tiered，铜1/银3/金5）。

**后端（BossController.java 为主）**
- `POST /boss/start`：入参 `{mode,title,categoryId,difficulty}`；建场后自动抽首题/选第一人（MANUAL 不选人）；血量 `target_rounds`：CLASS/GROUP=班级人数 N，RANDOM/MANUAL=`min(N, setting boss.random_target 默认20)`。
- `POST /boss/judge`：入参 `{bossId,studentId,quizId(抽背空),result}`；PASS 加分扣血、FAIL 只记录不扣血；未击杀自动 `advance()` 切题切人；hp≤0 → KILLED，发击杀奖+全班同庆，GROUP 发前二组组员奖，CLASS 本轮全对发团结奖。
- `advance()`：题库场先抽题；CLASS 按花名册顺序、GROUP 按座位列/排顺序（一轮完 round_no+1）、RANDOM 随机避开上一人、MANUAL 不选人。
- `GET /boss/sessions`（今昨场次列表）、`GET /boss/state?bossId=`、`GET /boss/report?bossId=`（含小组排名）；`ensureTurn()` 后端重启后对 ACTIVE 场重建内存轮次。
- 小组排名用相关子查询统计各组 PASS/FAIL（避免 seat_assignment JOIN boss_hit 的笛卡尔积连乘）。
- `AchievementScanner` 加 `CLASS_UNITY` 规则：数 `pet_log` 中 `biz_ref LIKE 'boss:%:unity:%'` 去重场次数定档。

**前端（Boss.vue 为主）**
- 大厅：标题 + ➕新建战场 + 场次卡（ACTIVE「继续战斗」/ 结束「查看战报」）。
- 新建弹窗：模式 4 选卡片、标题输入（默认「M月D日 · 模式名」可改）、题库下拉（空=🎤抽背）、难度（选题库才出现）。
- 战斗大屏：模式/标题/轮次进度；题目卡（抽背显示「🎤 抽背中」）；答题人卡含其宠物图；底部「✅答对 / ❌答错」（MANUAL 带点名下拉）；PASS 时宠物从答题人区飞向怪兽（fixed + CSS transition FLIP）。
- 战报弹窗：对错统计/击杀者/小组排名（**仅 GROUP 模式渲染**）/答题明细。

## 五、验收标准

- 大厅可新建四模式场、可继续 ACTIVE 场、结束场可看报告；进行中场无删除入口。
- 题库场：进入自动出第一题，判定后自动切题切人；大屏 state 不含答案。
- 抽背场：无题库也能判定，quizId 传 null。
- 随机/班级/小组：答对答错都自动切人；点名模式不自动选人、未选人名不能判定。
- 血量 = target_rounds × hit_per_pass，答对人次约等于 target_rounds 才击杀，不会被秒。
- 击杀：击杀者 +10、全班 +2；小组前二组员各 +5（第三组及以后无）；班级整轮全对全班 +3 且触发团结成就。
- 大屏 PASS 时宠物飞向怪兽并扣血抖动。
- E2E 全绿；后端重启后 ACTIVE 场刷新大屏能恢复当前轮次不空等。

## 八、本轮优化（P3 · 2026-09-07）：布局 + 小组一组一怪 + 叫人顺序

老师 4 点：
1. 大屏**怪兽移到最左**；选中学生后在**右侧大尺寸显示该生宠物**（答对时宠物从右侧飞向怪兽）。
2. CLASS/GROUP **不再随机抽人**：按座位列顺序一列一列挨个叫，**保证每个学生都叫到**；GROUP 显示「第几组」；GROUP 下方**不显示个人分数**，改显**小组分数前三榜**，名次变动有 FLIP 平移动画、被挤出前三有掉落动画。
3. GROUP **一组一怪**：怪血量 = 该组组员数，每人答对掉 1 滴；整组全对击杀本组怪 → **只给该组组员**加优胜分；**不要最后一击**个人奖、不发全班同庆；有人答错该组打不空 → **不加分，自动换下一组新怪**；全部组打完收尾。
4. 已确认：所有加分走 `PetService.award` → 写 `pet.exp`（**宠物成长值**，clamp 0..MAX_EXP 重算等级、记 pet_log）。

**已确认决策**：未击杀组 =「换下一组·不加分」；小组榜按**答对题数**排名；击杀奖**只发该组组员**（无最后一击、无全班同庆）。

**后端（BossController.java）**
- 新增助手 `groupCols()`（座位列号）、`groupMembers(col)`（列内组员按排号）、`classSeq()`（座次列序 + 未排座学生补队尾，保证人人叫到）、`countGroupHits(col)`。
- `start()`：GROUP 校验全员已排座（座位数 < 花名册数则提示先排座）；`hit_per_pass=1`、`target_rounds=小组数`、开局血量 = 第一组人数。
- `advance()` GROUP 状态机：`round_no`=第几组（1 起），`boss_hit.group_col`=物理列号；组内按排号挨个叫，整组答完 → 切下一组并 `UPDATE round_no,hp_total,hp_left`（新怪血量=下一组人数）；全部组答完 → 有任意组整组击杀置 `KILLED`，否则 `ESCAPED`。
- `judge()`：GROUP 某组 hp≤0 仅调 `awardGroupKill(col)` 奖励**该列组员**（biz `boss:{id}:group:{col}:{sid}` 幂等）；无 `kill_score`/`kill_all`。
- `awardGroupWins`（前二组）→ `awardGroupKill`（单组）；`groupRanking()` 补 `killed`（pass≥members）；`stateOf()` GROUP progress 含「第 N 组 + 组内 done/total + groupCount」并返回 `groupTop3`。

**前端（Boss.vue）**
- 战场改三栏：怪兽靠左 / 中间题目·答题人·战绩 / **右侧大宠物**（`petEl`，答对飞行起点由 `.picker-card` 改到大宠物）。
- GROUP 用 `<transition-group name="grp">` 渲染小组前三（🥇🥈🥉、第N组、✅ pass/人数、👑已击败，当前组高亮）；`.grp-move` FLIP 移动 + `.grp-leave-to` 掉落淡出。
- `progressText` GROUP 显示「第 N 组 · 组内 x/y」；战报小组榜按 `killed` 标 👑；MODES 文案改一组一怪口径。

**验证**：JDK17 编译 EXIT=0；8088 重启；前端 build EXIT=0；独立 `boss-group-tmp.spec.js` **2 passed**（全对→每组怪血量=组员数/每人 1 滴/人人各答一次/整组击杀；某组一人答错→该组 `killed=false pass=members-1` 不加分、其余组击杀、整场 KILLED）。E2E 11k GROUP 段同步重写（座次备份→`/seat/auto` 全员排座→跑完 `/seat/move` 还原原布局，临时学生由花名册删除级联清座）。

## 九、本轮优化（P4 · 2026-09-07）：大屏动效 + 点名座位表 + 题库入口 + 主动收场

老师反馈：①怪兽/宠物待机不动、攻击特效太小；②点名模式改用座位表点人；③默认蛋要用云小龙蛋图；④题库要快捷入口；⑤每场要能主动结束。

**大屏动效（Boss.vue）**
- 修 bug：怪兽受击 `.hurt` class 常驻会永久覆盖待机摆动 → 受击动画 0.5s 后移除 class 恢复待机。
- 待机幅度加大：怪兽 `bossIdle`（摇摆±4°+上浮 20px，2.3s）、宠物 `petIdle`（上浮 26px+左右摆，2s）。
- 攻击：飞行宠物 64→120px、带金光旋转冲刺；命中瞬间在怪兽处生成 💥 + 冲击波环；判定状态延迟到命中回调才落（扣血/抖怪/切人与碰撞同步）；飞出时原位宠物淡出。
- 排版：三栏居中（`space-between`→`justify-content:center` + max-width），小组模式信息栏紧凑化防 922 高度溢出。

**点名模式座位表（Boss.vue）**
- 去掉底部点名下拉，中区平铺座位表（读 `/seat/grid`，按行/列/过道 CSS grid 渲染）。
- 座位三色：选中=蓝、答对=绿、答错=红、空座=虚线；不显示分数排行（✅❌ 计数挪到答题人行）。
- 右侧宠物/答题人名跟随座位表选中的学生（修了点名模式 `pickedStudentId` 恒空导致右侧永远是蛋的 bug）。

**默认蛋**：未选人/未领养统一用云小龙蛋图 `/pets/dragon_egg.webp`（`petImgOf(null)`），不再用 emoji 🥚；Boss 页加载 `/pet/skins` 同步皮肤缓存，自创皮肤不再错显云龙。

**题库快捷入口**：新建战场弹窗题库下拉下方加链接，直接打开 `QuizDlg`（与宠物园同一组件）新增/管理题目，关闭后刷新题库下拉。

**主动收场**
- 后端新增 `POST /boss/end`：仅 ACTIVE 可结束；GROUP 已有整组击杀→KILLED（保留击败战绩），其余→ESCAPED；清内存 session、SSE 推 state/killed。
- 前端四个模式战斗中底部加「🏁 结束本场」，二次确认后收场，结束自动出战报/返回列表。

**验证**：后端 JDK17 编译 EXIT=0、8088 重启、`/boss/end` 实测返回正常；前端 build EXIT=0。
