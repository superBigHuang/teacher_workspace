# 奖牌进阶 + 辨识度 + 座位展示 + 宠物联动成就 —— 需求说明（✅ 已落地）

> 2026-09-02。来源：成就系统上线后使用反馈。状态：**已实施完成，build/E2E 通过**（落地结果见文末）。
> 关联：`doc/需求/学生成就系统/需求说明.md`（成就系统已上线）、`doc/需求/座次表显示与打印/需求说明.md`（seat_display 显示偏好）。

## 背景与问题

1. **四色分不清**：铜点 `#c07a3e` 与金点 `#e8a526` 都偏暖橙；徽章底托铜/金也都偏橙，小尺寸一眼难分。
2. **奖牌不能升级**：期望"铜→银→金随表现进阶"。现状 tier 是定义表固定属性，达成只得固定等级。
3. **描述没写清门槛**：悬停卡只写达成条件，没写"什么样是金、什么样是银"。
4. **奖牌想挂到座位**：得分最高的 3 块奖牌放到座次表宠物上方，座位设置可开关。
5. **量要够、要有宠物联动**：多设计成就（哪怕部分暂不触发），并和班级宠物园联动。

## 现状事实（已核对代码）

- `achievement_def.tier` 固定，DataInitializer 播种写死；`student_achievement` 唯一键 `(user_id,student_id,def_id,term)`，扫描 `INSERT IGNORE`、**只发不撤**。点数 铜10/银30/金60/白金100。
- 规则返回 `Eval(met,progress)` 布尔 + 进度文本。DataInitializer 有 `ensureColumn(表,列,定义)` 幂等加列；内置播种 `count(user_id=0)>0 即跳过`（改内置需补幂等 UPDATE）。
- 宠物数据：`pet`（level 1~5、exp 满 280、adopted_at 非空=已领养、graduated_count 毕业次数、hatched、pet_key 种族）；`pet_exchange`（兑换记录 student_id/item_id/cost/status）；`pet_log`（成长值流水 source=MANUAL/AUTO_*）。
- `/seat/grid` 不含成就；花名册角标 🏅N 用本学期数；BadgeIcon 已按传入 tier 上色，可小尺寸复用。

## 已确认决策

1. 进阶机制本期做（配色说明 + 铜→银升级）。
2. 座位奖牌取**本学期** top3；「🏅奖牌」开关**默认开**（简易模式强制隐藏、打印不打）。
3. 只升不降不回收；升级刷新 awarded_at；满分达人按满分科目数分档；入门档统一铜。
4. **进阶范围全上**（含连续全勤，周粒度数据不足也先把阶梯定义好），并**新增宠物联动成就 + 一批内置手动模板**把量做起来。
5. **大满贯也进阶**：仍是"全部集齐"，档位 = 所有可进阶奖牌都达到的档位（木桶最低档）；**大满贯点数 = 普通档 ×5**。

## 方案二：铜→银→金 进阶模型

- 一枚可进阶成就 = 一条定义带三档阈值；学生一学期**只持有一枚 = 当前最高档**，升级=UPDATE 该行 tier。
- `achievement_def` 加 **`tiered`**（0 固定 / 1 三档）；三档阈值存 `rule_params`：`{"tiers":[{"tier":"BRONZE","min":10},{"tier":"SILVER","min":20},{"tier":"GOLD","min":30}]}`（min=最低达成值，越大越好）。
- `student_achievement` 加 **`tier`**（当前持有档）；老数据 NULL，展示/计点回退 def.tier（不回填、不破坏）。唯一键不变；点数实时按 tier 统计（金 60），升级自动涨点、**无需补差**。
- 扫描：算出实际值 → 比对三档取最高满足档；无记录+达成→INSERT（庆祝获得）；有记录+更高档→UPDATE tier+awarded_at（庆祝升级）；档≤持有（含排名回落）→不动（只升不降）。
- 进度指向下一档："值日 15 次，当前🥉，再 5 次升🥈"；满档"已达最高🥇"。

## 方案三：新增成就把量做起来（宠物联动 + 手动模板）

- **宠物联动 AUTO（4 条，数据已支撑）**：萌宠相伴（领养，固定铜）、萌宠成长（Lv3/4/5 进阶）、毕业典礼（毕业 1/2/3 进阶）、小店达人（兑换 1/3/5 进阶）。Scanner 扩展宠物数据源：一次查全班 `pet` + `pet_exchange` 计数，内存聚合（无 N+1）。
- **学习补充 AUTO（1 条）**：成绩前列（最近考试总分前 10/5/3，进阶）。
- **内置手动模板 MANUAL（约 8 条，开箱即授、不参与扫描/大满贯）**：体育之星、艺术之星、音乐之星、助人为乐、文明礼仪、阅读之星、演讲达人、科技小达人（等级铜/银搭配，图标从现有 22 枚 badges 分配）。老师"授予学生"时直接可选，不依赖数据——快速把量做起来。
- 改造后内置成就：固定 AUTO 7 条 + 可进阶 AUTO 7 条 + 大满贯 1 条 + 手动模板约 8 条 ≈ **23 条**（原 11 条）。
- 宠物成就天然进座位 top3：宠物 Lv5/毕业等会变成奖牌挂到座位宠物上方，达成"宠物联动"。

## 方案四：大满贯进阶（集齐 + 全升档）

- **集齐判定不变**：本学期每个"启用中、非大满贯"的 AUTO 成就该生都有记录（任意档）。
- **大满贯档位 = 所有可进阶 AUTO 成就当前持有档的最低档（木桶）**；固定档成就只要求"持有"（单科状元/班委等固定铜不拖低档位）：
  - 集齐（可进阶成就至少全铜）→ **🥉大满贯**
  - 集齐 且 7 条可进阶成就**全部≥银** → **🥈大满贯**
  - 集齐 且 7 条可进阶成就**全部=金** → **🥇大满贯**
- **点数 = 普通档 ×5**：铜 50 / 银 150 / 金 300（金大满贯 300 点为全站最高，碾压普通金 60，终极荣誉）。
- 扫描器在其余 AUTO 评定完后最后算大满贯：先判集齐，再取可进阶档 min；只升不降。
- 白金 PLATINUM 枚举保留（不破坏老数据），本期大满贯用铜/银/金三档、trophy 奖杯图标区分；白金留作未来跨学年终极。

## 方案五：座位宠物上方挂本学期 top3

- 座位卡顶部、宠物正上方横排 ≤3 枚迷你 BadgeIcon（size≈20px），`title` 显成就名；点击座位仍开宠物详情。

- 数据：新增 `GET /api/achievement/seat-medals`——内部先 `scanner.scan(uid)`（静默幂等），再一条 SQL 查全班本学期 `student_achievement JOIN achievement_def`，按档点数降序、内存每生取前 3，返回 `{ studentId:[{icon,tier,name}] }`。前端座次页 onMounted 与 /seat/grid、/pet/pets 并行拉。
- 开关：座位设置「显示」区加「🏅奖牌」，存 `seat_display.fields.medal`（默认 1，watch 自动持久化，老偏好缺省按默认）。简易模式隐藏、打印不打。

## 落地结果（2026-09-02 完成）

**改动文件**：后端 4（schema.sql、DataInitializer、AchievementScanner、AchievementController）+ 前端 4（BadgeIcon、Roster、AchievementBoard、Seat）+ E2E 1 + 本文档。

### 后端要点

- **schema**：`achievement_def.tiered`（TINYINT 默认 0）、`student_achievement.tier`（VARCHAR(16) NULL，老数据 NULL/空串展示计点回退 def.tier，不回填）；rule_params 扩 VARCHAR(500)。
- **DataInitializer**：ensureColumn 两列幂等加列；`migrateBuiltinAchievements()` 幂等迁移——4 条老内置（劳动/进步/满分/连续全勤）按 rule_type UPDATE 为 tiered=1+三档 params；按 name 幂等 INSERT 5 条新 AUTO（萌宠相伴固定铜 / 萌宠成长 Lv3-4-5 / 毕业典礼 1-2-3 / 小店达人 1-3-5 / 成绩前列前10-5-3）+ 8 条 MANUAL 模板（builtin=1，不扫描不进大满贯）。内置定义 11 → 24 条。
- **AchievementScanner**：`Eval` 带达成档；`tierOf` 三档取最高满足档（RANK_TOP 为 smallerBetter）；宠物数据源一次查全班（pet.level/adopted_at、pet_badge/pet_exchange 本学期计数）内存聚合；RANK_TOP 总分竞赛并列排名（1,1,3）；只升不降（medalPoints 比较，档≤持有不动）；newAwards 元素带 `tier`/`kind`（award 新获得、upgrade 升级带 oldTier）；大满贯集齐后取可进阶持有档木桶最低档，点数 ×5（50/150/300），老白金 100 点保留（铜 50 不顶白金，银 150/金 300 才升）。
- **AchievementController**：新增 `GET /achievement/seat-medals`（内部先静默 scan 不抛错 → 一条 SQL 查全班本学期 sa JOIN def JOIN student → 内存按有效点数降序每生取 top3，返回 `{sid:[{icon,name,tier}]}`）；board/student 点数统计统一改 Java 聚合（替换 SQL CASE tier）；`PUT /def/{id}` builtin 分支支持 ruleParams 整体写回（三档门槛编辑，保留 fullScore 等非阈值字段）。

### 前端要点

- **BadgeIcon**：四色底托拉开——铜古铜棕 `#c98a5b→#8a5326`、银纯银灰去紫 `#f4f6fa→#a9b3c2`、金亮金黄 `#fff0a0→#f5b800`、白金炫彩保留。
