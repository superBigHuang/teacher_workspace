# 注册隐藏（自助注册下线）— 需求说明

## 一、背景与问题

平台定位为校内单教师/少账号使用的工作台，账号由管理员统一开通。原登录页带「✨ 注册」Tab，任何人可自助注册账号并自动播种一套班级脚手架——对内网部署场景无必要，且自助注册意味着任何人都可建号访问，存在安全风险。

## 二、目标与非目标

**目标**

- 登录页去掉注册入口，只保留登录表单，提示「还没有账号？请联系管理员开通」。
- 后端 `/api/auth/register` 端点下线（不是仅前端隐藏）：直接调用该接口返回非 200。
- 既有账号（admin、e2e_teacher 等库中预置账号）登录不受影响。

**非目标**

- 不做管理员后台「建号」界面（本期用 SQL/UserDataSeeder 预置即可，KISS）。
- 不删 `UserDataSeeder`（DataInitializer 仍用它给预置账号播种默认数据）。
- 不影响改密码、当前账号等其余 auth 接口。

## 三、改动范围

**后端**

- `auth/AuthController.java`：删除 `register()` 端点及对 `UserDataSeeder` 的依赖注入；类注释更新为「登录 / 当前账号 / 修改密码（自助注册已下线）」。
- `config/WebConfig.java`：JWT 拦截器放行清单移除 `/api/auth/register`（端点已删，保留放行无意义）。

**前端**

- `views/Login.vue`：删除登录/注册 Tab 切换、注册表单与 `register()` 方法；登录表单下加提示「还没有账号？请联系管理员开通」；清理 Ticket 图标等无用引用与样式。

**测试**

- `e2e/tests/e2e.spec.js`：登录页步骤新增断言——页面无注册 Tab、`POST /api/auth/register` 返回非 200；E2E 专用账号 `e2e_teacher` 改为依赖库中预置（注释说明），不再走注册接口。

## 四、验收标准

1. 登录页只显示登录表单，无注册 Tab/按钮。
2. 直接 `POST /api/auth/register` 返回非 200（端点不存在）。
3. admin、e2e_teacher 等预置账号正常登录，各模块功能不受影响。
4. 全量 E2E 通过。

## 五、待确认问题

- 管理员「建号」目前靠 SQL 手动建号 + UserDataSeeder 播种（e2e_teacher 即如此预置）。若后续需要后台建号界面，单独立需求。

## 六、落地结果

- 后端 `mvn package` 通过，8088 已重启加载新代码；前端 `npm run build` 通过。
- 全量 E2E（playwright，单用例 1 passed，约 2.1 分钟）通过：
  - 登录页无注册 Tab；`POST /api/auth/register` 直接调用返回非 200（404，端点已不存在）。
  - admin、e2e_teacher 预置账号登录正常，8 大模块走查、速记、删除验证、刷新保活不受影响。
- 已知外部问题（与本需求无关）：`/ai/test` 外部中转站渠道仍 ok=false，E2E 期间曾临时 try/catch 放宽、跑完已恢复严格断言（验证无「临时放行」残留）。需老师检查中转站模型渠道配置。
- 新账号预置方式：SQL 建号（`sys_user`）+ 启动时 `DataInitializer` 经 `UserDataSeeder` 播种默认数据；e2e_teacher 即按此预置。
