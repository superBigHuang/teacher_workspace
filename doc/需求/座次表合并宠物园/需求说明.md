# 座次表合并宠物园（宠物"坐"在座位上）

## 背景与问题描述

- 班级宠物园 v1 为独立页面（/pet，侧边栏 🐾宠物园），与座次表割裂：老师看座位时看不到宠物，要切页。
- 用户要求：宠物园不单独成页，与座次表结合——宠物就"坐"在学生座位上，教室即宠物园。

## 目标与非目标

- 目标：
  - 座次表页承载全部宠物园功能（领养/评价/批量评价/毕业/荣誉榜/小商店/评价项管理）；
  - 座位卡显示宠物形态图、Lv 徽章、迷你成长条、负面状态角标；点击座位看宠物详情/领养；
  - 未排座学生在网格下方以宠物卡形式呈现，功能不缺失；
  - 删除独立宠物页、路由与侧边栏入口。
- 非目标：
  - 后端 API、数据表、升级规则、E2E 业务断言全部不变；
  - 花名册宠物角标/档案抽屉宠物 tab、成绩页宠物发奖、设置页自动扣分开关不变。

## 需求范围（方案 A：宠物坐在座位上，用户已选定）

- 前端：
  - 新增 `src/composables/usePets.js`：从 PetGarden.vue 抽取全部宠物状态与操作逻辑（弹窗状态、领养/评价/撤回/毕业/荣誉榜/商店/评价项 CRUD、飘字），供 Seat.vue 复用；
  - `Seat.vue` 改造：
    - 工具栏增加 🏆荣誉榜 / 🛍小商店 / ⚙评价项 / 📝批量评价；
    - 座位卡：宠物图（呼吸动画/负面状态特效）+ Lv 徽章 + 迷你经验条 + 状态角标（💫🥶🩹🎓）；未领养显示灰蛋，点击座位即领养；
    - 拖拽交换座位与点击查看宠物区分（pointer 位移 >6px 判定为拖拽）；批量模式下禁用拖拽、显示勾选框；
    - 网格下方「未排座学生」区：原宠物卡网格（含领养按钮/勾选），保证未排座学生宠物可照料；
    - 搬入全部宠物弹窗（领养/详情/评价/毕业仪式/荣誉榜/商店/评价项管理）；
  - 删除 `PetGarden.vue`、`/pet` 路由、侧边栏 🐾宠物园 导航项；
  - Roster.vue 两处提示文案"宠物园"改"座次表"。
- E2E：11f 步骤 `goto('/pet')` 改 `/seat`；宠物卡选择器适配 `.seat, .pet-card`（座位/未排座区二选一）；其余 API 断言与花名册断言不变。

## 影响范围

- 前端：Seat.vue（重写模板/脚本）、router/index.js、MainLayout.vue、Roster.vue（文案）、新增 composable、删除 PetGarden.vue；
- E2E：e2e.spec.js 11f 段 UI 部分；
- 后端：无改动。

## 验收标准

- 座次表页：座位上可见宠物图/Lv/成长条；点击已领养座位开详情（流水/撤回/评价/毕业）；点击未领养座位可领养；
- 荣誉榜/商店/评价项管理/批量评价在座次表页全部可用；
- 未排座学生在下方宠物卡区可领养/评价；
- 拖拽交换座位不误触发宠物弹窗；批量模式勾选与浮动条正常；
- /pet 路由不存在，侧边栏无宠物园入口；
- E2E 全绿（含 11f 宠物全链路与 12 刷新登录）。

## 待确认问题

- 无（合并形态已经用户确认为方案 A）。

## 方案结论摘要

composable 抽逻辑 + Seat.vue 承载 UI，后端零改动；2026-09-01 实施。
