# 消息推送改为右侧半页抽屉（入口放修改密码旁）

> 2026-09-03。老师原话："消息推送也改成半页的，放修改密码旁边好了。"经确认用**右侧滑出抽屉**。

## 背景与问题

个人设置页的「🔔 消息推送」原本是一张跨两列的大卡片（`.candy-card.wide`），含总开关 + 企业微信/钉钉/Bark 三渠道 + 事件勾选 + 保存，内容很长，把设置页撑得很高。推送配置属于低频操作，不需要常驻占整行。

## 目标

- 把消息推送配置收进一个**右侧滑出的半页抽屉**（el-drawer，rtl，宽约 520px）。
- 设置页只保留一个**入口按钮，放在「修改密码」卡片标题旁**；推送开启时按钮带绿色小圆点提示。
- 抽屉内功能与原卡片完全一致（开关、教程链接、三渠道 webhook/secret、发送测试、事件勾选、保存、隐私提示）。

## 方案结论（纯前端 `Settings.vue`）

- 删除跨两列的 `.push-card` 大 section。
- 「修改密码」卡标题改为 `.card-head`（flex 两端）：左侧 `🔒 修改密码`，右侧 `el-button.plain.push-entry`「🔔 消息推送」，`push.enabled` 时显示绿色 `.push-on-dot`。
- 新增 `<el-drawer v-model="pushDrawer" direction="rtl" size="520px" class="push-drawer">`：顶部 `.push-toggle`（总开关 + 图文教程链接），下方原三渠道/事件/保存表单整体搬入。
- 新增 `pushDrawer` ref；`loadPush()` 仍在 onMounted 调用（用于入口圆点状态与抽屉初始值）。
- 设置卡数量由 6 张变为 5 张。

## 影响范围
- 前端：`frontend/src/views/Settings.vue`（模板 + 少量 CSS + 一个 ref）。
- 后端/数据：无改动（推送接口 `/push/config`、`/push/test` 不变）。
- E2E：个人设置步骤改为断言 5 张卡、点 `.push-entry` 后 `.push-drawer` 可见并含开关/教程/三渠道/事件，关闭后隐藏。

## 验收标准
1. 设置页不再有横跨整行的推送大卡片；「修改密码」标题旁有「🔔 消息推送」按钮。
2. 点按钮从右侧滑出约半页宽抽屉，内含开关、三渠道、发送测试、事件勾选、保存；配置/保存/测试均正常。
3. 推送已开启时入口按钮显示绿色圆点。
4. 关闭抽屉后设置页布局正常（两列瀑布流不受影响）。

## 落地结果（2026-09-03 完成）

- `Settings.vue`：删除跨两列的 `.push-card` 大卡；「修改密码」卡标题改 `.card-head` 两端布局，右侧加 `.push-entry`「🔔 消息推送」按钮（开启时显示绿色圆点 `.push-on-dot`）；新增 `<el-drawer class="push-drawer" direction="rtl" size="520px">`，总开关/教程/三渠道/发送测试/事件勾选/保存整体搬入；新增 `pushDrawer` ref，`loadPush` 仍在 onMounted 调用（供圆点状态）。设置卡由 6 张变 5 张。
- 顺带修复真实 bug：`.candy-card::before` 右上角装饰圆盖在按钮上拦截 pointer events（老师手点也点不到），加 `pointer-events: none`。
- 后端/接口：无改动。
- E2E：个人设置步骤改断言 5 张卡、点 `.push-entry` 后 `.push-drawer` 可见（开关/教程/三渠道/事件齐全），关闭后隐藏。全量 E2E 通过（1 passed，1.7m）。
