# 课表自定义节次：新增节次自动顺延 + 时间选择框 + 课间/上课时长可配

> 2026-09-03。老师反馈 bug + 优化（截图：自定义节次弹窗，新增的节次名字都是"第X节"、时间都是 00:00-00:45）。

## 背景与问题

`Timetable.vue` 的"自定义节次"弹窗点"新增节次"时，`addPeriod()` 硬编码：
```js
await http.post('/timetable/period', { name: '第X节', startTime: '00:00', endTime: '00:45', isBreak: 0 })
```
导致每加一节名字都叫"第X节"、时间都堆在 00:00-00:45，老师还得逐条手改，无法用。

## 目标

1. 新增节次自动命名为"第 N 节"（N = 现有最大"第 X 节"序号 + 1）。
2. 时间自动顺延：开始 = 最后一个节次（含课间，按 sort）的结束时间 + **课间时长**；结束 = 开始 + **上课时长**。
3. 开始/结束时间改用**时间选择框**（el-time-picker，时:分），不再用文本输入框。
4. **课间时长、上课时长可在设置中调整**，默认 10 分钟 / 40 分钟。

## 方案结论（前端为主，无表变更）

- **设置存储**：复用 user 级 `setting` 表 key-value（经 `POST /dashboard/settings`），新增两个 key：
  - `period_break_min`（课间分钟，默认 10）
  - `period_class_min`（每节上课分钟，默认 40）
  - 在"自定义节次"弹窗表格上方放两个 `el-input-number`（课间/每节上课 分钟），改后即时保存；打开弹窗时从 `/dashboard/settings` 读取。
- **新增节次 `addPeriod()` 前端计算**（后端 `POST /timetable/period` 入参不变，仍收 name/startTime/endTime/isBreak）：
  - 序号：`periods` 中 name 匹配 `/^第(\d+)节$/` 的最大数字 + 1（没有则从 1 开始；"早自习"等非"第N节"命名不占序号）。
  - 基准：取 `periods` 按 `sort` 排在最后的节次（含课间，如午休结束时间）的 `endTime`。
  - `startTime = 基准 endTime + 课间分钟`；`endTime = startTime + 上课分钟`（HH:mm 字符串按分钟加减、跨午自动进位）。
  - isBreak=0。
- **时间选择框**：开始/结束两列 `el-input` 改为 `el-time-picker`，`format="HH:mm"` `value-format="HH:mm"` size="small"，`@change="updPeriod(row)"`。

## 影响范围

- 前端：`frontend/src/views/Timetable.vue`（弹窗模板 + addPeriod 计算 + 两个时长 ref/加载/保存 + HH:mm 加减工具函数）。
- 后端：无改动（period 接口已支持任意 name/startTime/endTime）。
- 数据：无表变更；setting 新增两个可选 key（缺省回落 10/40）。
- E2E：新增节次命名/顺延时间断言、时间选择框存在、时长配置可保存（临时节次 afterAll 删除，不污染真实节次）。

## 验收标准

1. 点"新增节次"，新节自动命名"第 N 节"（接续现有最大序号），开始时间 = 上一节结束 + 课间，结束 = 开始 + 上课时长。
2. 开始/结束为时间选择框（点选时:分），非文本输入；改动后自动保存。
3. 设置里把课间改成 15、上课改成 45 后，再新增节次按 15/45 顺延；缺省回落 10/40。
4. 不影响已有节次、课间开关、删除、排课。

## 落地结果（2026-09-03 完成）

- 前端 `Timetable.vue`：
  - 节次弹窗表格上方加"新增节次顺延：课间 [10] 分钟 / 每节上课 [40] 分钟"两个 `el-input-number`，改后即时 `POST /dashboard/settings`（key `period_break_min`/`period_class_min`，缺省回落 10/40），打开弹窗时读取。
  - 新增节次 `addPeriod()` 前端计算：序号取现有 `/^第(\d+)节$/` 最大序号 +1；开始 = 最后节次（按 sort，含课间）结束时间 + 课间分钟；结束 = 开始 + 上课分钟（HH:mm 按分钟加减、跨天回绕）；一个节次都没有时从 08:00 起。
  - 开始/结束列 `el-input` 改 `el-time-picker`（format/value-format="HH:mm"），改动 @change 自动保存。
- 后端：无改动（`POST /timetable/period` 已收 name/startTime/endTime；`/dashboard/settings` 为通用 kv upsert，直接存两个新 key）。
- E2E：新增 7b 步骤——断言时间选择框与两个时长配置存在；默认 10/40 新增节次命名"第N节"且时间顺延正确；改 15/45 后再新增按新值顺延且设置持久化；step finally + afterAll 双清理新增节次并恢复时长 10/40。全量 E2E 通过。
