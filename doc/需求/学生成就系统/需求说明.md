# 学生成就系统（PSN 奖杯式徽章）需求说明

## 背景与问题
- 班级管理以"记录问题"为主（迟到、未交、违纪），正向激励缺乏载体：表扬靠口头、发奖靠即兴，学生没有持续可见的"荣誉感积累"。
- 库里已有一学期的正向/中性数据（成绩进步、全勤、作业、值日、班委），但只用于统计和评语，没有变成学生能"挣到"的东西。
- 参考 PSN 奖杯机制：徽章墙 + 灰解锁条件 + 稀有度 + 获得瞬间反馈，把日常表现游戏化。

## 目标
1. **徽章墙**：每个学生有成就徽章（铜🥉/银🥈/金🥇/白金🏆），已获得彩色+获得日期，未获得灰色+悬停显示"如何获得"+当前进度。
2. **两种获得方式**：老师手动授予（自定义成就，灵活覆盖比赛/好人好事等系统无法判断的场景）；系统按数据条件**自动颁发**（规则引擎扫描，幂等）。
3. **即时反馈**：扫描到新成就时弹庆祝提示（"🎉 小茗获得了「进步之星」"）。
4. **全班成就榜**：每枚徽章多少人获得、自动稀有度标注（常见/稀有/史诗/传说）。

## 非目标
- 不做学生/家长登录端（老师端展示，可投屏/截图发家长群）。
- 不做积分商城/实物兑换。
- 本期不做老师自建自动规则编辑器（内置 10 条规则可启用/停用/调阈值；自定义规则 v2）。

## PSN 机制 → 班级场景映射

| PSN | 本系统 |
|---|---|
| 铜/银/金/白金奖杯 | 铜🥉/银🥈/金🥇 成就 + 白金🏆「大满贯」（集齐当期全部自动成就） |
| 未获得灰色奖杯+解锁说明 | 灰色徽章 + 悬停 popover：成就名、条件描述、**当前进度**（如"排名已提升 3/5 名"） |
| 获得率稀有度 | 按本班获得率自动标：常见 >50% / 稀有 20~50% / 史诗 5~20% / 传说 <5% |
| 奖杯总数/等级 | 已获 X/总 Y、三色计数、成就点数（铜10/银30/金60/白金100） |
| 跳杯瞬间 | 扫描新发徽章时 ElNotification 庆祝弹窗（一次扫描多条合并展示） |

## 需求范围

### A. 成就展示
1. **学生档案抽屉新增「🏅 我的成就」区**：
   - 顶部：**累计**已获 X 枚、🥉n 🥈n 🥇n 🏆n、成就点数（跨学期永久累积）；
   - 徽章墙按学期分组：当前学期组默认展开（已获得=3D 彩色图标+tier 底托+名称+获得日期；未获得=灰色，grayscale+透明度 .3），历史学期组折叠可展开回看；
   - 悬停/点击徽章：popover 显示名称、等级、描述（如何获得）、获得学期与日期或当前进度（如"值日 6/10 次"）。
2. **花名册学生卡角标**：卡片右上角小徽章 🏅N（N=本学期获得数，0 不显示）。
3. **成就榜**（花名册页内新增「🏅 成就榜」视图切换，不新增侧边栏菜单）：
   - 左：成就定义列表（emoji/名称/等级/获得人数/稀有度标签/启用开关）；
   - 右：选中成就后显示已获得学生名单+日期，未获得学生灰色名单；
   - 顶部操作：🔄 扫描自动成就、➕ 创建成就、🎁 授予学生。
4. **工作台联动**：扫描发现新徽章时弹庆祝通知；评语素材增加"本学期成就 X 枚/代表成就名"，AI 评语可引用。

### B. 手动成就与授予
- 创建自定义成就：名称、emoji 图标（选或填）、等级（铜/银/金）、描述（如何获得，展示在灰色徽章上）。
- 授予：选成就 + 多选学生（可跨班？仅本班+任课班？本期班主任班）+ 备注（选填，如"校运会跳远第一名"）。
- 撤销：误发可收回（删除获得记录，带二次确认）。
- 自定义成就可编辑/删除；内置成就不可删，只能停用。

### C. 自动成就规则引擎（内置 10 条，按学期区间，复用学期聚合层）

| 成就 | 等级 | 规则（rule_type / 默认参数） |
|---|---|---|
| 全勤之星 | 🥈 | 学期迟到=0 且 缺勤=0 且 请假天数=0（allowLeave 参数可放宽） |
| 作业全勤 | 🥈 | 学期作业未交次数=0 |
| 纪律标兵 | 🥈 | 学期违纪条数=0 |
| 进步之星 | 🥈 | RANK_UP：最近两次考试排名提升 ≥ 5 名 |
| 全科优秀 | 🥇 | ALL_EXCELLENT：最近一次考试所有科目 ≥ 优秀线 |
| 单科状元 | 🥉 | SUBJECT_TOP：任一科目班级最高分（并列都得） |
| 满分达人 | 🥉 | SCORE_FULL：任一科目满分（100/120/150 按满分线参数，默认 100） |
| 劳动能手 | 🥉 | DUTY_COUNT：值日参与 ≥ 10 次（duty_roster 记录） |
| 班委担当 | 🥉 | COMMITTEE：committee 有任职记录 |
| 连续全勤 | 🥉 | CONTINUOUS_ATTENDANCE：连续 4 周无迟到/缺勤（weeks 参数可调） |
| 大满贯 | 🏆 | COLLECTOR：集齐当期所有**启用中**的自动成就 |

- **扫描时机（KISS，不做事件埋点）**：打开成就榜/学生抽屉成就区时静默自动扫描一次（规则仅 10 条 SQL，轻量、幂等：已颁发不重复）；也提供「🔄 扫描」手动按钮；成绩导入后顺带触发一次。
- 扫描器对每条启用规则算出"满足条件的 studentIds"，与已颁发记录 diff 后插入，返回新颁发清单 → 前端庆祝弹窗。
- 进度计算复用规则逻辑：未获得徽章悬停时返回 current/target（如"值日 6/10 次"、"排名提升 3/5 名"）；无法量化进度的规则显示条件文本。
- 阈值参数老师可在成就榜编辑（内置成就可改参数与启用状态，不可删）。

### D. 学期维度（永久累积、按学期分组）
- 获得记录带 `term`（学期标签，取 setting.term）；自动成就按 term_start/term_end 区间统计。
- 每学期独立评定（同一成就每学期最多一枚，uk 含 term）；徽章**永久累积不清零**，徽章墙按学期分组展示、累计总数置顶；新学期扫描自动评定新一期，历史记录保留。

## 数据方案
- 新表 `achievement_def`（成就定义）：
  `id, user_id BIGINT DEFAULT 0（0=系统内置模板，全局共享；>0=老师自定义）, name, description, icon(emoji), tier(BRONZE/SILVER/GOLD/PLATINUM), kind(MANUAL/AUTO), rule_type, rule_params(VARCHAR/JSON 字符串, 如 '{"minRankUp":5}'), enabled TINYINT DEFAULT 1, builtin TINYINT DEFAULT 0, created_at`
  - 内置模板由 DataInitializer 幂等播种（user_id=0，所有账号查询时 UNION 可见）；老师自定义 per-user。
- 新表 `student_achievement`（获得记录）：
  `id, user_id, student_id, def_id, term, source(AUTO/MANUAL), remark, awarded_at, created_at`
  - 唯一键 `uk_user_student_def_term (user_id, student_id, def_id, term)`（幂等）。
- DataInitializer 幂等建表 + 播种内置 10+1 条成就定义。

## 后端接口（AchievementController，`/api/achievement`，按 uid 隔离）
| 接口 | 说明 |
|---|---|
| GET /defs | 定义列表（内置+本账号自定义），含每枚获得人数、稀有度 |
| POST /def | 创建自定义成就（kind=MANUAL 或自定义 AUTO 本期不开放） |
| PUT /def/{id} | 编辑：自定义可全改；内置仅 enabled/rule_params |
| DELETE /def/{id} | 删除自定义成就（其获得记录一并删除） |
| POST /scan | 扫描全班自动成就（当前学期），返回新颁发 `[{studentId,name,defId,defName,icon,tier}]` |
| GET /student/{studentId}?term= | 某生徽章墙：全部定义+该生获得状态+获得日期+进度 current/target |
| POST /award | 手动颁发 `{defId, studentIds:[], remark}` |
| DELETE /revoke/{recordId} | 撤销一条获得记录 |
| GET /board?term= | 成就榜：每生点数/三色计数排行 + 每枚成就获得名单 |

## 影响范围
- 后端：新增 AchievementController + AchievementScanner（规则引擎，复用学期聚合服务 TermStatsService 的迟到/未交/违纪/排名数据）；DataInitializer 建表+内置成就播种；成绩导入完成后触发扫描。
- 前端：学生抽屉加「🏅 我的成就」区（徽章网格+popover 进度+学期切换）；花名册加「成就榜」视图（定义管理/授予/扫描/庆祝通知）；学生卡角标；评语素材加成就字段。
- 与请假闭环/评语/通知单共用学期区间聚合层，无新数据采集负担。

## 验收标准
- 学生抽屉成就区：彩色已获得徽章带日期；灰色徽章悬停显示条件与进度（如"值日 6/10 次"）；三色计数与总数正确。
- 手动流程：创建自定义成就 → 授予 3 名学生 → 三人徽章墙立即出现 → 撤销一人后该人徽章消失。
- 自动扫描：admin 班 40 人数据扫描后，全勤/作业/纪律/成绩类规则至少各触发若干人（与库中数据一致：有迟到记录的学生不得全勤之星）；重复扫描不产生重复记录；新颁发触发庆祝通知。
- 大满贯：仅集齐全部启用自动成就的学生获得；停用某枚自动成就后大满贯条件随之变化。
- 稀有度：获得率 <5% 的成就显示"传说"标签。
- 数据隔离：A 账号自定义成就与颁发记录 B 账号不可见；内置成就两账号均可见。
- E2E：API 链路——创建→授予→学生墙可见→扫描返回数组且幂等（二次扫描新颁发为 0）→撤销→消失。

## 图标方案（已定：Fluent UI Emoji 3D，本地打包）
- **图标来源**：微软 Fluent UI Emoji 3D 版（github.com/microsoft/fluentui-emoji，**MIT 协议可商用**），3D 光泽拟物、多巴胺配色，符合"可爱/拟物/小学生喜欢"。
- **打包方式**：精选约 20 枚 PNG（256×256，透明底）放 `frontend/public/badges/`，随前端打包，**不依赖 CDN**（部署环境网络不可控）；老师创建成就时从图标库网格点选，不用 emoji、不支持上传（KISS）。
- **已实测下载验证**（样本在 `doc/需求/学生成就系统/icon-samples/`，开发时拷入 public/badges/）：
  trophy、medal-1st/2nd/3rd、star、glowing-star、sparkles、rocket、crown、gem、broom、check、books、pencil、shield、bell、sun、party、hundred(💯)、grad-cap、sports-medal、memo。
- **等级视觉**（铜/银/金/白金由系统渲染，不依赖图标本身颜色）：图标置于圆形渐变底托上——铜（橙棕渐变）/银（淡紫灰渐变）/白金（炫彩渐变）/金（金黄渐变）；已获得=彩色+tier 色发光阴影+悬浮微动效；未获得=`filter: grayscale(.95) opacity(.3)`。
- **内置成就图标分配**：全勤之星=check、作业全勤=books、纪律标兵=shield、进步之星=rocket、全科优秀=glowing-star、单科状元=crown、满分达人=hundred、劳动能手=broom、班委担当=medal-1st、连续全勤=sun、大满贯=trophy。

## 待确认（结论）
1. ~~按学期 vs 永久累积~~ → **永久累积、按学期分组**：徽章记录永久保留，学生徽章墙顶部为累计总数（🏅总枚数/点数/三色计数，跨学期累计），下方按学期分组展示（"2026秋季"组、"2027春季"组…），可折叠回看；自动成就每学期独立评定（同一成就不同学期可各得一枚，记录带 term）。
2. ~~扫描时机~~ → **静默 + 手动**：打开成就榜/抽屉成就区静默扫描一次 + 「🔄 扫描」按钮 + 成绩导入后触发。
3. ~~内置规则阈值~~ → **通过**（进步 5 名、值日 10 次、连续全勤 4 周、满分线 100，且都可在成就榜编辑）。
4. ~~成就点数~~ → **做**：铜 10 / 银 30 / 金 60 / 白金 100，累计点数与枚数并列展示；成就榜按点数排行。
5. ~~图标形式~~ → **Fluent 3D 图标库**（见上节），不用 emoji。

## 方案结论摘要
两张新表 + 一个 Controller + 一个规则扫描器；自动成就的数据全部来自现有学期聚合层，规则引擎与评语素材共用底层；展示寄生在学生抽屉和花名册（不加菜单项）；游戏化反馈（灰色进度+稀有度+跳杯庆祝）是灵魂，工作量集中在前端徽章墙交互。建议排在评语/通知单之后开发（复用 TermStatsService）。

## 落地结果（2026-09-01 完成）

### 后端
- **两表**（schema.sql 幂等建表）：`achievement_def`（id/user_id[0=内置全局共享]/name/description/icon/tier/kind[MANUAL|AUTO]/rule_type/rule_params JSON/enabled/builtin）、`student_achievement`（user_id/student_id/def_id/term/source[AUTO|MANUAL]/remark/awarded_at，唯一键 `uk_sa(user_id,student_id,def_id,term)` 保证幂等）。
- **DataInitializer.seedBuiltinAchievements()**：启动幂等播种 11 条内置定义（user_id=0、builtin=1）：全勤之星/作业全勤/纪律标兵（银）、进步之星/全科优秀（金）、单科状元/满分达人/劳动能手/班委担当/连续全勤（铜）、大满贯（白金）。
- **AchievementScanner**（service，规则引擎）：`scan(uid)` 复用 TermStatsService.materials() 学期素材（late/absent/leaveDays/homeworkMissing/discipline/dutyCount/roles/rankChange）+ 最近一次考试 score 明细（loadLatestExam 一次查回全班，内存按生/按科聚合，无 N+1）；10 条规则判定后与已颁发记录 diff，`INSERT IGNORE` 幂等颁发；**大满贯最后评定**（集齐全部启用中且非大满贯的 AUTO 成就）。`evaluateStudent(uid,sid)` 返回每枚 AUTO 成就的达成状态 + 未达成进度文本（如"值日参与 6/10 次"、"达优秀线 2/3 科（优秀线 85 分）"、"排名已提升 3/5 名"）。CONTINUOUS_ATTENDANCE 按 KISS 落地为"学期内无迟到无缺勤"。
- **AchievementController**（/api/achievement，9 接口，全部 uid 隔离）：GET /defs（含 points/获得人数/稀有度/获得名单）、POST /def（自定义 MANUAL）、PUT /def/{id}（内置仅 enabled+rule_params 阈值；自定义全字段）、DELETE /def/{id}（仅自定义，连带删除获得记录）、POST /scan（返回 newAwards 清单）、GET /student/{id}（累计 stats[总枚数/点数/四色计数]+本学期全部启用徽章[获得状态/日期/备注/未获得进度]+历史学期折叠组）、POST /award（多选学生+备注，INSERT IGNORE 幂等）、DELETE /revoke/{recordId}、GET /board（点数排行 rankings + 定义列表 defs）。
- **稀有度**：按本班获得率分档——<5% 传说 LEGENDARY / 5~20% 史诗 EPIC / 20~50% 稀有 RARE / >50% 常见 COMMON / 0 人 NONE。
- **扫描触发点**：① 打开成就榜/抽屉成就区静默扫描；② 成就榜「🔄 扫描」手动按钮；③ **成绩导入后 ScoreController 自动触发**（newAwards 随导入响应返回，前端弹庆祝）。
- **评语素材扩展**：TermStatsService.materials() 新增 achievementCount（本学期成就枚数）/topAchievement（最高 tier 代表成就名）；AiService 评语 prompt 闪光点段与 CommentGenerator 模板句式均引用（"本学期你收获了 X 枚成就徽章，「XX」更是格外闪亮"）。
- RosterController 删学生级联补 `student_achievement`。

### 前端
- **BadgeIcon 组件**（components/）：Fluent 3D PNG + tier 圆形渐变底托（铜橙棕/银淡紫灰/金金黄/白金炫彩）；未获得灰底托+`grayscale(1) opacity(.3)`；获得时跳杯动画（cubic-bezier 弹性缩放 + tier 色发光圈扩散）。
- **AchievementBoard.vue**（花名册内「🏅 成就榜」视图切换，不加侧边栏菜单）：左右两栏——左=定义列表（3D 图标/等级·点数标签/稀有度标签/获得人数/启用开关/自定义删除），右=选中成就详情（描述+等级+稀有度+自动/手动 + 🎁授予学生[多选+备注] + 已获得学生名单[日期/来源标签/备注/撤销二次确认]）；顶部「🏆 点数排行」视图（四色计数+点数降序，前三🥇🥈🥉）；「➕ 创建成就」对话框（名称/铜银金等级/22 枚图标网格点选/描述）；🔄 扫描后 ElNotification 合并庆祝（按成就分组"小茗 等 N 人获得「XX」"）。
- **Roster.vue**：学生卡右上角 🏅N 金色角标（进页面静默扫描+拉榜，不弹通知）；抽屉新增第三个 tab「🏅 我的成就」（累计 🏅枚数/⭐点数/四色计数置顶 → 本学期徽章网格，el-popover 悬停显示条件描述+获得日期备注 或 未获得进度 → 历史学期 el-collapse 折叠回看；切 tab 时静默扫描，新成就弹庆祝）。
- **Score.vue**：成绩导入响应携带 newAwards 时弹合并庆祝通知。
- 22 枚 Fluent 3D PNG 就位 `frontend/public/badges/`（随包部署，无 CDN 依赖）。
