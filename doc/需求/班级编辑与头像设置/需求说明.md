# 班级标签可编辑 + 教师头像设置

## 背景与问题描述

- 工作台问候卡的班级标签「班主任 · 初一(1)班（N人）」「任课 · 初一(2)班」只读展示，新注册账号（如 hn1）想改班级名没有入口；个人设置页也没有班级管理。
- 侧边栏左下角头像写死 🐻，教师无法设置自己的头像。

## 目标与非目标

- 目标：
  - 工作台问候卡「✏️ 编辑」弹窗中可改班主任班名称、可增删改任课班；保存后问候卡标签即时更新；
  - 侧边栏左下角头像可点击，从 emoji 头像库中选择保存，全站侧边栏即时生效。
- 非目标：
  - 不做图片上传头像（v2 再议；emoji 与现有马卡龙风格一致、零存储成本）；
  - 班级数据仍复用 class_info 表与 /timetable/class 增删改接口（已存在），后端不新增班级接口；
  - 班主任班不可删除（学生/座次/课表均挂它），仅可改名。

## 需求范围

- 后端：SettingsController.saveProfile 增加 avatar 设置项（存 setting 表 k='avatar'，emoji 字符）；GET /settings/profile 本就返回全部 setting，无需改。
- 前端 MainLayout.vue：
  - user-avatar 从写死 🐻 改为 avatar 状态（默认 🐻）；onMounted 拉 /settings/profile 取 avatar/displayName/school，avatar 缓存 localStorage；
  - 点头像弹「选择头像」弹窗：emoji 网格（动物 + 笑脸 + 职业，约 40 个），选中即 PUT /settings/profile {avatar} 保存并即时刷新。
- 前端 Dashboard.vue：
  - 编辑弹窗加「我的班级」区：班主任班名称输入框；任课班列表（每行名称 + 删除按钮）+ 新增任课班输入框；
  - 保存：班主任班 PUT 改名（不存在则 POST type=HOMEROOM）；任课班改名 PUT、删除 DELETE（连带课表/座次清理，接口已实现）、新增 POST type=SUBJECT；
  - 保存后重新加载班级，问候卡标签更新；多个任课班时标签以顿号连接。

## 影响范围

- 后端：SettingsController.java（1 行 upsertSetting）；
- 前端：MainLayout.vue、Dashboard.vue；
- E2E：头像设置 API 断言 + 班级改名还原。

## 验收标准

- 工作台编辑弹窗可改班主任班名、增删任课班，保存后标签文案即时变化；
- 点侧边栏头像可选 emoji 保存，刷新页面/重新登录后头像保持；
- E2E 全绿。

## 待确认问题

- 无。

## 方案结论摘要

班级复用现有 /timetable/class 接口、前端在问候卡编辑弹窗补入口；头像存 setting.avatar（emoji），侧边栏弹窗选择。2026-09-01 实施。
